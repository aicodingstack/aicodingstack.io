# Apa itu AI Coding Stack dan bagaimana ini membantu para pengembang?

AI Coding Stack adalah direktori dan repositori metadata yang lengkap untuk ekosistem coding AI. Ini menyediakan platform terpusat untuk menemukan, membandingkan, dan mengeksplorasi alat pengembangan bertenaga AI termasuk IDE seperti VS Code dan Cursor, asisten baris perintah seperti Claude Code, model LLM, dan penyedia API. Alih-alih mencari di berbagai sumber yang terpisah, AI Coding Stack memberikan spesifikasi detail, harga, dan perbandingan fitur, semua dalam satu tempat.

# Bagaimana cara menggunakan AI Coding Stack?

AI Coding Stack adalah direktori berbasis web yang dapat Anda jelajahi langsung di aicodingstack.io. Tidak perlu instalasi! Cukup:

- **Jelajahi Kategori**: Telusuri IDE, CLI, Model, dan Penyedia
- **Bandingkan Alat**: Gunakan fitur perbandingan untuk melihat spesifikasi dan harga berdampingan
- **Baca Dokumentasi**: Akses panduan pengaturan dan praktik terbaik untuk setiap alat
- **Tetap Terbarui**: Periksa versi dan spesifikasi terbaru untuk semua alat

Platform ini terus diperbarui dengan alat dan informasi baru seiring ketersediaannya.

# Alat coding AI dan penyedia LLM apa saja yang terdaftar di AI Coding Stack?

AI Coding Stack menampilkan katalog lengkap alat dan layanan coding AI:

- **IDE**: Visual Studio Code, Cursor, TRAE, dan editor kode bertenaga AI lainnya
- **CLI**: Claude Code, Codex, dan asisten AI baris perintah lainnya
- **Ekstensi**: GitHub Copilot, Cline, Continue, Roo Code, dan plugin asisten kode AI lainnya
- **Model**: DeepSeek, Kimi K2, GLM, Qwen, GPT, Claude, dan model AI terdepan lainnya
- **Penyedia**: OpenAI, Anthropic, DeepSeek, Moonshot, OpenRouter, SiliconFlow, dan lainnya

Direktori ini terus diperbarui seiring munculnya alat dan penyedia baru.

# Apakah AI Coding Stack open source? Dapatkah saya berkontribusi?

Ya, AI Coding Stack sepenuhnya open source dan dirilis di bawah lisensi Apache 2.0. Proyek ini menyambut kontribusi dari komunitas! Anda dapat berkontribusi dengan:

- Menambahkan atau memperbarui metadata alat di direktori manifests (ides.json, clis.json, models.json, providers.json)
- Melaporkan ketidakakuratan atau informasi yang sudah usang
- Menyarankan alat baru untuk ditambahkan
- Meningkatkan dokumentasi dan panduan
- Mengirimkan pull requests

Kunjungi [repositori GitHub](https://github.com/aicodingstack/aicodingstack.io) untuk mulai berkontribusi ke ekosistem coding AI.

# Bagaimana AI Coding Stack membantu saya memilih alat yang tepat?

AI Coding Stack menyediakan fitur perbandingan detail dan spesifikasi untuk membantu Anda mengambil keputusan yang tepat:

- **Perbandingan Berdampingan**: Bandingkan beberapa alat berdasarkan fitur kunci, harga, dan kemampuan
- **Spesifikasi Detail**: Lihat jendela konteks, batas token, tingkat harga, dan dukungan platform
- **Pelacakan Versi Terbaru**: Tetap terbarui dengan rilis dan fitur terbaru
- **Dikelola Komunitas**: Manfaatkan informasi yang dikurasi dan ditinjau oleh pengembang
- **Metadata Lengkap**: Akses dokumentasi resmi, tautan unduhan, dan sumber daya komunitas

Semua informasi diatur untuk membantu Anda mengidentifikasi dengan cepat alat mana yang paling sesuai dengan alur kerja pengembangan Anda.
