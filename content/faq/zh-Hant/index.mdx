# AI Coding Stack 是什麼？它如何協助開發者？

AI Coding Stack 是 AI 程式開發生態系統的完整目錄與詮釋資料儲存庫。它提供集中式平台，讓你探索、比較並瞭解各種 AI 驅動的開發工具，包括 VS Code 和 Cursor 等 IDE、Claude Code 等命令列助理、LLM 模型與 API 供應商。你不必分散搜尋各種來源，就能在同一處查看詳細規格、價格與功能比較。

# 如何使用 AI Coding Stack？

AI Coding Stack 是可直接在 aicodingstack.io 瀏覽的網站目錄，不需要安裝。你可以：

- **探索類別**：瀏覽 IDE、CLI、模型與供應商
- **比較工具**：使用比較功能並排查看規格與價格
- **閱讀文件**：查閱各項工具的設定指南與最佳實務
- **掌握更新**：查看所有工具的最新版本與規格

平台會隨新工具與資訊推出而持續更新。

# AI Coding Stack 收錄哪些 AI 程式開發工具與 LLM 供應商？

AI Coding Stack 收錄完整的 AI 程式開發工具與服務：

- **IDE**：Visual Studio Code、Cursor、TRAE，以及其他整合 AI 的程式碼編輯器
- **CLI**：Claude Code、Codex，以及其他命令列 AI 助理
- **擴充套件**：GitHub Copilot、Cline、Continue、Roo Code，以及其他 AI 程式開發助理外掛
- **模型**：DeepSeek、Kimi K2、GLM、Qwen、GPT、Claude，以及其他主流 AI 模型
- **供應商**：OpenAI、Anthropic、DeepSeek、Moonshot、OpenRouter、SiliconFlow 等

目錄會隨新工具與供應商出現而持續更新。

# AI Coding Stack 是開放原始碼嗎？我可以參與貢獻嗎？

是的，AI Coding Stack 完全開放原始碼，並採用 Apache 2.0 授權條款。專案歡迎社群參與，你可以：

- 在 manifests 目錄中新增或更新工具詮釋資料（ides.json、clis.json、models.json、providers.json）
- 回報不正確或過時的資訊
- 建議收錄新工具
- 改善文件與指南
- 提交 pull request

請前往 [GitHub 儲存庫](https://github.com/aicodingstack/aicodingstack.io)，開始為 AI 程式開發生態系統做出貢獻。

# AI Coding Stack 如何協助我選擇合適的工具？

AI Coding Stack 提供詳細比較功能與規格，協助你做出有根據的決策：

- **並排比較**：依關鍵功能、價格與能力比較多項工具
- **詳細規格**：查看情境窗口、token 上限、價格方案與平台支援
- **最新版本追蹤**：掌握最新版本與功能
- **社群維護**：使用由開發者審查與整理的資訊
- **完整詮釋資料**：存取官方文件、下載連結與社群資源

所有資訊都經過整理，協助你快速找出最符合開發流程的工具。
