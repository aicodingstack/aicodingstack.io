# O que é AI Coding Stack e como ajuda os desenvolvedores?

AI Coding Stack é um diretório e repositório de metadados abrangente para o ecossistema de coding com IA. Fornece uma plataforma centralizada para descobrir, comparar e explorar ferramentas de desenvolvimento alimentadas por IA, incluindo IDEs como VS Code e Cursor, assistentes de linha de comando como Claude Code, modelos LLM e provedores de API. Em vez de pesquisar em recursos dispersos, AI Coding Stack oferece especificações detalhadas, preços e comparações de recursos, tudo em um só lugar.

# Como uso o AI Coding Stack?

AI Coding Stack é um diretório baseado na web que você pode navegar diretamente em aicodingstack.io. Não requer instalação! Simplesmente:

- **Explorar Categorias**: Navegue por IDEs, CLIs, Modelos e Provedores
- **Comparar Ferramentas**: Use o recurso de comparação para ver especificações e preços lado a lado
- **Ler Documentação**: Acesse guias de configuração e melhores práticas para cada ferramenta
- **Ficar Atualizado**: Verifique as versões e especificações mais recentes para todas as ferramentas

A plataforma é continuamente atualizada com novas ferramentas e informações conforme ficam disponíveis.

# Quais ferramentas de coding com IA e provedores de LLM estão listados no AI Coding Stack?

AI Coding Stack apresenta um catálogo abrangente de ferramentas e serviços de coding com IA:

- **IDEs**: Visual Studio Code, Cursor, TRAE e outros editores de código aprimorados com IA
- **CLIs**: Claude Code, Codex e outros assistentes de linha de comando
- **Extensões**: GitHub Copilot, Cline, Continue, Roo Code e outros plugins de assistente de código
- **Modelos**: DeepSeek, Kimi K2, GLM, Qwen, GPT, Claude e outros modelos de IA líderes
- **Provedores**: OpenAI, Anthropic, DeepSeek, Moonshot, OpenRouter, SiliconFlow e outros

O diretório é continuamente atualizado à medida que novas ferramentas e provedores surgem.

# O AI Coding Stack é open source? Posso contribuir?

Sim, AI Coding Stack é totalmente open source e lançado sob a licença Apache 2.0. O projeto recebe contribuições da comunidade! Você pode contribuir:

- Adicionando ou atualizando metadados de ferramentas no diretório manifests (ides.json, clis.json, models.json, providers.json)
- Relatando imprecisões ou informações desatualizadas
- Sugerindo novas ferramentas para adicionar
- Melhorando documentação e guias
- Enviando pull requests

Visite o [repositório GitHub](https://github.com/aicodingstack/aicodingstack.io) para começar a contribuir para o ecossistema de coding com IA.

# Como o AI Coding Stack me ajuda a escolher as ferramentas certas?

AI Coding Stack fornece recursos de comparação detalhados e especificações para ajudar você a tomar decisões informadas:

- **Comparação Lado a Lado**: Compare várias ferramentas em recursos principais, preços e capacidades
- **Especificações Detalhadas**: Visualize janelas de contexto, limites de tokens, níveis de preços e suporte de plataforma
- **Rastreamento de Última Versão**: Mantenha-se atualizado com os novos lançamentos e recursos
- **Mantido pela Comunidade**: Beneficie-se de informações curadas revisadas por desenvolvedores
- **Metadados Abrangentes**: Acesse documentação oficial, links de download e recursos da comunidade

Todas as informações são organizadas para ajudar você a identificar rapidamente quais ferramentas melhor se adaptam ao seu fluxo de trabalho de desenvolvimento.
