# ¿Qué es AI Coding Stack y cómo ayuda a los desarrolladores?

AI Coding Stack es un directorio completo y un repositorio de metadatos para el ecosistema de programación con IA. Proporciona una plataforma centralizada para descubrir, comparar y explorar herramientas de desarrollo potenciadas por IA, incluidos IDEs como VS Code y Cursor, asistentes de línea de comandos como Claude Code, modelos LLM y proveedores de API. En lugar de buscar en recursos dispersos, AI Coding Stack te ofrece especificaciones detalladas, precios y comparaciones de funciones, todo en un solo lugar.

# ¿Cómo uso AI Coding Stack?

AI Coding Stack es un directorio basado en web que puedes navegar directamente en aicodingstack.io. ¡No requiere instalación! Simplemente:

- **Explorar categorías**: Navega por IDEs, CLIs, Modelos y Proveedores
- **Comparar herramientas**: Usa la función de comparación para ver especificaciones y precios lado a lado
- **Leer documentación**: Accede a guías de configuración y mejores prácticas para cada herramienta
- **Mantenerse actualizado**: Consulta las últimas versiones y especificaciones de todas las herramientas

La plataforma se actualiza continuamente con nuevas herramientas e información a medida que están disponibles.

# ¿Qué herramientas de programación con IA y proveedores de LLM están listados en AI Coding Stack?

AI Coding Stack cuenta con un catálogo exhaustivo de herramientas y servicios de programación con IA:

- **IDEs**: Visual Studio Code, Cursor, TRAE y otros editores de código potenciados por IA
- **CLIs**: Claude Code, Codex y otros asistentes de IA de línea de comandos
- **Extensiones**: GitHub Copilot, Cline, Continue, Roo Code y otros complementos de asistente de código con IA
- **Modelos**: DeepSeek, Kimi K2, GLM, Qwen, GPT, Claude y otros modelos de IA líderes
- **Proveedores**: OpenAI, Anthropic, DeepSeek, Moonshot, OpenRouter, SiliconFlow y más

El directorio se actualiza continuamente a medida que surgen nuevas herramientas y proveedores.

# ¿AI Coding Stack es de código abierto? ¿Puedo contribuir?

Sí, AI Coding Stack es completamente de código abierto y se publica bajo la licencia Apache 2.0. ¡El proyecto recibe contribuciones de la comunidad! Puedes contribuir:

- Agregando o actualizando metadatos de herramientas en el directorio manifests (ides.json, clis.json, models.json, providers.json)
- Reportando inexactitudes o información desactualizada
- Sugerir nuevas herramientas para agregar
- Mejorando la documentación y las guías
- Enviando pull requests

Visita el [repositorio de GitHub](https://github.com/aicodingstack/aicodingstack.io) para comenzar a contribuir al ecosistema de programación con IA.

# ¿Cómo ayuda AI Coding Stack a elegir las herramientas adecuadas?

AI Coding Stack proporciona características de comparación detalladas y especificaciones para ayudarte a tomar decisiones informadas:

- **Comparación lado a lado**: Compara múltiples herramientas en función de funciones clave, precios y capacidades
- **Especificaciones detalladas**: Consulta ventanas de contexto, límites de tokens, niveles de precios y soporte de plataforma
- **Seguimiento de la última versión**: Mantente actualizado con los nuevos lanzamientos y funciones
- **Mantenido por la comunidad**: Benefíciate de una información curada revisada por desarrolladores
- **Metadatos completos**: Accede a documentación oficial, enlaces de descarga y recursos de la comunidad

Toda la información está organizada para ayudarte a identificar rápidamente qué herramientas se ajustan mejor a tu flujo de trabajo de desarrollo.
