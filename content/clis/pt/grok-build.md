## faq.items.0.question

O que é Grok Build?

## faq.items.0.answer

O Grok Build é o agente de programação no terminal de código aberto da xAI para explorar repositórios, editar código, executar comandos e concluir tarefas de desenvolvimento de ponta a ponta. Ele foi projetado para trabalhar diretamente em um projeto a partir de uma sessão de terminal.

## faq.items.1.question

Quais são os principais recursos do Grok Build?

## faq.items.1.answer

O Grok Build percorre o repositório e examina os arquivos relevantes para basear as mudanças no código atual.
