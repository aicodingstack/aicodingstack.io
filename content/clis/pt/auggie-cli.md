## answer

Auggie CLI é um agente autônomo de terminal alimentado pelo mecanismo de contexto da Augment da Augment.

## introduction

Auggie CLI permite, pelo terminal, usar o mecanismo de contexto para assistência ciente do código, executar trabalho autônomo em uma interface nativa de terminal e ligar a TUI interativa a fluxos automatizados.

## faq.items.0.question

O que é Auggie CLI?

## faq.items.0.answer

Auggie CLI é um agente de programação para terminal da Augment. Ele foi criado para usar o mecanismo de contexto para assistência ciente do código.

## faq.items.1.question

Como instalar Auggie CLI?

## faq.items.1.answer

Use o comando de instalação específico da plataforma mostrado nesta página ou siga a documentação oficial. Depois da instalação, inicie Auggie CLI com auggie.

## faq.items.2.question

Quais sistemas operacionais Auggie CLI aceita?

## faq.items.2.answer

Auggie CLI está disponível para macOS, Windows e Linux e inicia com auggie nas três plataformas.
