## faq.items.0.question

O que é Kilo Code CLI?

## faq.items.0.answer

Kilo Code CLI é a interface de terminal da Kilo para programação assistida por IA. Ela interpreta solicitações naturais como tarefas de geração, depuração e desenvolvimento.
