## answer

Cline CLI é um agente de programação headless para executar tarefas do Cline no terminal da Cline Bot.

## introduction

Cline CLI permite, pelo terminal, executar tarefas colaborativas de IA sem editor interativo, automatizar execução headless, como no GitHub Actions e ligar fluxos do Cline a bots do Discord e tíquetes do Linear.

## faq.items.0.question

O que é Cline CLI?

## faq.items.0.answer

Cline CLI é um agente de programação para terminal da Cline Bot. Ele foi criado para executar tarefas colaborativas de IA sem editor interativo.

## faq.items.1.question

Como instalar Cline CLI?

## faq.items.1.answer

Use o comando de instalação específico da plataforma mostrado nesta página ou siga a documentação oficial. Depois da instalação, inicie Cline CLI com cline.

## faq.items.2.question

Quais sistemas operacionais Cline CLI aceita?

## faq.items.2.answer

Cline CLI está disponível para macOS, Windows e Linux e inicia com cline nas três plataformas.

## faq.items.3.question

Quanto custa Cline CLI?

## faq.items.3.answer

A CLI de código aberto não cobra licença; a inferência de IA pode ser cobrada por uso e as condições Enterprise são personalizadas. Consulte a seção de preços.
