## answer

Amazon Q Developer CLI é um assistente CLI agêntico que entende o código e executa tarefas por diálogo natural da AWS.

## introduction

Amazon Q Developer CLI permite, pelo terminal, entender um repositório e ajudar com o contexto do código, executar tarefas solicitadas por diálogo adaptativo e usar o comando q no ambiente de desenvolvimento local.

## faq.items.0.question

O que é Amazon Q Developer CLI?

## faq.items.0.answer

Amazon Q Developer CLI é um agente de programação para terminal da AWS. Ele foi criado para entender um repositório e ajudar com o contexto do código.

## faq.items.1.question

Como instalar Amazon Q Developer CLI?

## faq.items.1.answer

Use o comando de instalação específico da plataforma mostrado nesta página ou siga a documentação oficial. Depois da instalação, inicie Amazon Q Developer CLI com q.

## faq.items.2.question

Quais sistemas operacionais Amazon Q Developer CLI aceita?

## faq.items.2.answer

Amazon Q Developer CLI está disponível para macOS, Windows e Linux e inicia com q nas três plataformas.

## faq.items.3.question

Quanto custa Amazon Q Developer CLI?

## faq.items.3.answer

Amazon Q Developer CLI tem uma opção gratuita e uma assinatura paga por usuário. Consulte a seção de preços e a fonte oficial para os limites e termos atuais.
