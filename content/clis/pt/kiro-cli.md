## answer

Kiro CLI é uma ferramenta de programação com IA para terminal da AWS, centrada em desenvolvimento orientado por especificações e equipada com hooks de agente, busca na web e assistência em linguagem natural.

## introduction

Kiro CLI parte de uma especificação escrita que continua sendo a referência do protótipo ao código de produção. Os hooks de agente podem acionar tarefas repetíveis, enquanto a busca na web traz contexto externo quando necessário. Depois da instalação, kiro-cli é executado no diretório do projeto no macOS, Windows ou Linux.

Desenvolvimento orientado por especificações

## capabilities.items.0.description

Requisitos e design são registrados primeiro em uma especificação, que passa a orientar o protótipo, as alterações de código e os objetivos de produção.

## capabilities.items.1.title

Hooks de agente e busca na web

## capabilities.items.1.description

Os hooks de agente acionam tarefas repetíveis, e a busca na web fornece informações externas quando a atividade exige mais contexto.

## capabilities.items.2.title

Assistência de programação em linguagem natural

## capabilities.items.2.description

A tarefa pode ser descrita em linguagem natural e continuar na mesma sessão de terminal para examinar, editar e verificar o projeto local.

## faq.items.0.question

O que é Kiro CLI?

## faq.items.0.answer

A ferramenta atende desenvolvedores que desejam orientar o agente por uma especificação explícita, em vez de depender apenas de um prompt improvisado. A AWS acrescenta automação no terminal e pesquisa externa.

## faq.items.1.question

O que é possível fazer com Kiro CLI?

## faq.items.1.answer

Kiro CLI vincula uma especificação duradoura à implementação, entrega ações repetitivas aos hooks e acrescenta contexto da web quando o repositório não basta.

## faq.items.2.question

Como começar a usar Kiro CLI?

## faq.items.2.answer

Siga as instruções oficiais de instalação para o seu sistema e depois execute kiro-cli no terminal aberto no diretório do projeto.

## faq.items.3.question

Quais sistemas operacionais são compatíveis com Kiro CLI?

## faq.items.3.answer

Kiro CLI é compatível com macOS, Windows e Linux. Antes da instalação, consulte na documentação oficial os requisitos de cada sistema.
