## answer

Kode é uma ferramenta de programação para terminal de código aberto da shareAI Lab que edita com o contexto do repositório, executa comandos e permite escolher vários modelos em uma experiência semelhante ao Claude Code.

## introduction

Kode entende o projeto pelo contexto de todo o código e cria alterações compatíveis com a estrutura existente, em vez de tratar cada arquivo de forma isolada. A edição e a execução de comandos fazem parte da mesma tarefa, e a experiência semelhante ao Claude Code permite trocar de modelo. Após a instalação, kode funciona no macOS, Windows ou Linux.
