## faq.items.0.question

O que é Claude Code?

## faq.items.0.answer

Claude Code é um agente de programação para terminal da Anthropic. Ele foi criado para entender e explicar código com o contexto do repositório.

## faq.items.1.question

Como instalar Claude Code?

## faq.items.1.answer

Use o comando de instalação específico da plataforma mostrado nesta página ou siga a documentação oficial. Depois da instalação, inicie Claude Code com claude.

## faq.items.2.question

Quais sistemas operacionais Claude Code aceita?

## faq.items.2.answer

Claude Code está disponível para macOS, Windows e Linux e inicia com claude nas três plataformas.
