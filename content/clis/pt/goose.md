## faq.items.0.question

O que é Goose CLI?

## faq.items.0.answer

Goose CLI é a interface de terminal do Goose, um agente de IA local e de código aberto para programação, pesquisa, automação e outros fluxos com vários provedores de modelos. Ele foi projetado para trabalhar diretamente em um projeto a partir de uma sessão de terminal.
