## faq.items.0.question

O que é Antigravity CLI?

## faq.items.0.answer

Antigravity CLI é um agente de programação para terminal da Google. Ele foi criado para invocar e monitorar agentes Antigravity pelo terminal.

## faq.items.1.question

Como instalar Antigravity CLI?

## faq.items.1.answer

Use o comando de instalação específico da plataforma mostrado nesta página ou siga a documentação oficial. Depois da instalação, inicie Antigravity CLI com agy.

## faq.items.2.question

Quais sistemas operacionais Antigravity CLI aceita?

## faq.items.2.answer

Antigravity CLI está disponível para macOS, Windows e Linux e inicia com agy nas três plataformas.
