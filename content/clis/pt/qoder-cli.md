## answer

Qoder CLI é o assistente proprietário da Alibaba que reúne geração de código, depuração, TUI, chat integrado e trabalho orientado a projetos numa só interface de terminal.

## introduction

Qoder CLI gera código no terminal, ajuda a diagnosticar problemas e permite interagir com a tarefa por meio de uma TUI ou de chat integrado. A gestão do projeto se combina diretamente com geração de código e depuração. Após a instalação, qodercli é executado no diretório do projeto no macOS, Windows ou Linux.
