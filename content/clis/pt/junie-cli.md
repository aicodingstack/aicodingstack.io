## faq.items.0.question

O que é Junie CLI?

## faq.items.0.answer

O Junie CLI é o agente de terminal independente de modelo da JetBrains para planejar mudanças, editar repositórios, executar ferramentas e usar configurações de agente reutilizáveis. Ele foi projetado para trabalhar diretamente em um projeto a partir de uma sessão de terminal.
