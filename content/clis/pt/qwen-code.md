## answer

Qwen Code é um agente de repositório de código aberto para quem precisa estudar uma base de código grande, alterar arquivos, executar comandos e escolher conexões Qwen ou compatíveis com OpenAI.

## introduction

Qwen Code usa o contexto de um repositório grande antes de modificar arquivos e executar os comandos necessários na mesma tarefa. Ele pode usar Qwen ou serviços com interface compatível com OpenAI. Depois da instalação e da configuração do modelo, qwen é executado no projeto no macOS, Windows ou Linux.
