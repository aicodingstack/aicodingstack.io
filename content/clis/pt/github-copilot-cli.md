## answer

GitHub Copilot CLI é um agente de IA para terminal que responde perguntas, escreve e depura código, modifica projetos e trabalha com o GitHub para criar pull requests.

## introduction

Ele pode atuar como parceiro interativo de programação ou ser executado de forma programática em scripts e automações. A partir de um repositório, pode investigar código, implementar e depurar alterações, usar o contexto do GitHub e preparar ou criar pull requests.

## capabilities.items.0.title

Responder com o contexto do projeto

## capabilities.items.0.description

Pergunte sobre a estrutura do repositório, detalhes de implementação ou erros desconhecidos e receba respostas baseadas no projeto atual.

## capabilities.items.1.title

Escrever, depurar e modificar código

## capabilities.items.1.description

Peça ao agente para implementar recursos, diagnosticar falhas e editar arquivos enquanto trabalha no projeto pelo terminal.

## capabilities.items.2.title

Trabalhar com GitHub e pull requests

## capabilities.items.2.description

Use o contexto e os fluxos do GitHub para examinar atividades do repositório e preparar ou criar pull requests pela linha de comando.

## faq.items.0.question

O que é GitHub Copilot CLI?

## faq.items.0.answer

É o agente de programação nativo de terminal do GitHub, criado para investigar código, implementar alterações, depurar problemas e concluir fluxos do GitHub.

## faq.items.1.question

Quais são os principais recursos do GitHub Copilot CLI?

## faq.items.1.answer

Ele pode responder perguntas sobre o código, escrever e depurar código, modificar arquivos do projeto, trabalhar com o GitHub e criar pull requests.

## faq.items.2.question

GitHub Copilot CLI funciona de modo interativo e programático?

## faq.items.2.answer

Sim. Você pode usá-lo como agente interativo no terminal ou chamá-lo programaticamente em scripts, automações e integrações repetíveis.
