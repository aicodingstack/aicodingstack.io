## answer

O Kimi Code CLI é o agente de terminal da Moonshot AI para explorar repositórios, editar arquivos, executar comandos, usar ferramentas MCP e compartilhar fluxos com sua extensão do VS Code.

## introduction

O desenvolvedor pode começar em um repositório local e deixar Kimi examinar o código relevante, aplicar mudanças e usar as ferramentas necessárias, sem limitar a sessão a conselhos de chat. Quando a visão do editor for mais adequada, o mesmo trabalho continua na extensão Kimi Code para VS Code.

## capabilities.items.0.title

Exploração de repositórios e edição de arquivos

## capabilities.items.0.description

O Kimi navega pelo repositório, examina os arquivos relevantes e aplica edições com base no contexto encontrado.

## capabilities.items.1.title

Comandos e ferramentas MCP

## capabilities.items.1.description

Ele pode executar comandos locais e se conectar a ferramentas MCP, indo além de simples sugestões de código.

## capabilities.items.2.title

Fluxos compartilhados com a extensão do VS Code

## capabilities.items.2.description

A CLI e a extensão Kimi Code para VS Code mantêm a continuidade entre o terminal e o editor.

## faq.items.0.question

O que é Kimi Code CLI?

## faq.items.0.answer

A ferramenta é voltada a quem deseja um agente atuando no repositório local pelo terminal e, quando necessário, a passagem para o VS Code. A Moonshot AI fornece a CLI e a extensão associada.

## faq.items.1.question

Quais são os principais recursos do Kimi Code CLI?

## faq.items.1.answer

O fluxo conecta alterações baseadas no repositório a comandos locais e ferramentas MCP, permitindo escolher entre terminal e editor conforme a tarefa.

## faq.items.2.question

Como instalar e iniciar Kimi Code CLI?

## faq.items.2.answer

Escolha nesta página o método adequado ao seu sistema, siga as orientações oficiais e inicie a sessão no repositório que Kimi deve examinar.

## faq.items.3.question

Quais plataformas Kimi Code CLI suporta?

## faq.items.3.answer

Oferece suporte a macOS, Windows e Linux.
