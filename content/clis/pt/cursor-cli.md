## answer

Cursor CLI é um agente de linha de comando com IA para escrever, revisar e modificar código da Anysphere.

## introduction

Cursor CLI permite, pelo terminal, escrever e modificar código diretamente no terminal, revisar código com ajuda de IA e usar modelos avançados de vários provedores.

## faq.items.0.question

O que é Cursor CLI?

## faq.items.0.answer

Cursor CLI é um agente de programação para terminal da Anysphere. Ele foi criado para escrever e modificar código diretamente no terminal.

## faq.items.1.question

Como instalar Cursor CLI?

## faq.items.1.answer

Use o comando de instalação específico da plataforma mostrado nesta página ou siga a documentação oficial. Depois da instalação, inicie Cursor CLI com cursor-agent.

## faq.items.2.question

Quais sistemas operacionais Cursor CLI aceita?

## faq.items.2.answer

Cursor CLI está disponível para macOS, Windows e Linux e inicia com cursor-agent nas três plataformas.
