Qwen Code 是面向终端用户的开源仓库 Agent，可检查大型代码库、修改文件、执行命令，并选择 Qwen 或 OpenAI 兼容的模型连接。

## introduction

Qwen Code 会先结合大型代码库的上下文理解仓库，再在同一任务中编辑文件并执行所需命令。它既可使用 Qwen，也可连接 OpenAI 兼容接口；安装和模型配置完成后，可在 macOS、Windows 或 Linux 的项目目录中运行 qwen。
