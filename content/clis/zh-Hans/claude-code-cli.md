## answer

## faq.items.1.question

如何安装 Claude Code？

## faq.items.1.answer

请使用本页显示的对应平台安装命令，或按官方安装文档操作。安装完成后，运行 claude 启动 Claude Code。

## faq.items.2.question

Claude Code 支持哪些操作系统？

Claude Code 支持 macOS、Windows 和 Linux，并在三个平台上都通过 claude 启动。
