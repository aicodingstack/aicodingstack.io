## answer

Antigravity CLI 是 Google 推出的面向 Antigravity 的终端优先 Agent 编排工具。

## introduction

借助 Antigravity CLI，开发者可以直接在终端中调用并监控 Antigravity Agent、协调 subagent、多文件编辑、工具、MCP 和 skills，以及在本地或通过文档所述的远程 SSH 支持开展工作。

## faq.items.0.question

Antigravity CLI 是什么？

## faq.items.0.answer

Antigravity CLI 是 Google 的终端编程 Agent，主要用于从终端调用并监控 Antigravity Agent。

## faq.items.1.question

如何安装 Antigravity CLI？

## faq.items.1.answer

请使用本页显示的对应平台安装命令，或按官方安装文档操作。安装完成后，运行 agy 启动 Antigravity CLI。

## faq.items.2.question

Antigravity CLI 支持哪些操作系统？

## faq.items.2.answer

Antigravity CLI 支持 macOS、Windows 和 Linux，并在三个平台上都通过 agy 启动。
