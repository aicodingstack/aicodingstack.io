## answer

Kimi Code CLI 是 Moonshot AI 的终端编码代理，支持代码仓库探索、文件编辑、命令执行、MCP 工具，以及与其 VS Code 扩展共享工作流。

## introduction

开发者可以从本地仓库开始，让 Kimi 查找相关代码、完成修改并调用支持任务所需的工具，而不是只获得一段对话式建议。需要编辑器视图时，还可以在 Kimi Code 的 VS Code 扩展中继续同一项工作。

## capabilities.items.0.title

代码仓库探索和文件编辑

## capabilities.items.0.description

Kimi 会浏览仓库、检查相关文件，并结合代码库上下文应用修改。

## capabilities.items.1.title

命令和 MCP 工具

## capabilities.items.1.description

它能执行本地命令并连接 MCP 工具，不局限于提供代码建议。

## capabilities.items.2.title

与 VS Code 扩展共享的工作流

## capabilities.items.2.description

CLI 与 VS Code 的 Kimi Code 扩展支持在终端和编辑器之间延续同一工作流。

## faq.items.0.question

Kimi Code CLI 是什么？

## faq.items.0.answer

它适合希望由 Agent 在终端中直接处理本地仓库，同时又需要切换到 VS Code 的开发者。Moonshot AI 同时提供 CLI 和配套编辑器扩展。

## faq.items.1.question

Kimi Code CLI 的核心能力是什么？

## faq.items.1.answer

其工作方式把代码库感知的修改、本地命令和 MCP 工具连接起来，并允许开发者根据任务在终端与编辑器之间切换。

## faq.items.2.question

如何安装并启动 Kimi Code CLI？

## faq.items.2.answer

选择页面为当前操作系统提供的方式，按照官方说明完成设置，再从需要 Kimi 检查的仓库开始会话。

## faq.items.3.question

Kimi Code CLI 支持哪些平台？

## faq.items.3.answer

支持 macOS、Windows 和 Linux。 可在这些系统的本地终端工作流中使用。

## faq.items.4.question

在哪里查看 Kimi Code CLI 的价格？

## faq.items.4.answer

Kimi Code CLI 是开源软件；托管模型的可用性、使用条件和可能产生的费用以 Moonshot AI 官方服务信息为准。
