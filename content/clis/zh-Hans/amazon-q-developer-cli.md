## answer

Amazon Q Developer CLI 是 AWS 推出的能够理解代码库并通过自然对话执行任务的 Agent 型 CLI 助手。

## introduction

借助 Amazon Q Developer CLI，开发者可以直接在终端中理解仓库并结合代码上下文提供帮助、通过自适应自然语言对话执行用户要求的任务，以及在本地开发环境中使用 q 命令。

## faq.items.0.question

Amazon Q Developer CLI 是什么？

## faq.items.0.answer

Amazon Q Developer CLI 是 AWS 的终端编程 Agent，主要用于理解仓库并结合代码上下文提供帮助。

## faq.items.1.question

如何安装 Amazon Q Developer CLI？

## faq.items.1.answer

请使用本页显示的对应平台安装命令，或按官方安装文档操作。安装完成后，运行 q 启动 Amazon Q Developer CLI。

## faq.items.2.question

Amazon Q Developer CLI 支持哪些操作系统？

## faq.items.2.answer

Amazon Q Developer CLI 支持 macOS、Windows 和 Linux，并在三个平台上都通过 q 启动。
