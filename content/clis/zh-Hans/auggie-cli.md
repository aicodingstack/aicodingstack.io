## answer

Auggie CLI 是 Augment 推出的由 Augment 上下文引擎驱动的自主终端 Agent。

## introduction

借助 Auggie CLI，开发者可以直接在终端中借助上下文引擎提供理解代码库的辅助、通过原生终端界面执行自主任务，以及把交互式 TUI 与自动化工作流结合起来。

## faq.items.0.question

Auggie CLI 是什么？

## faq.items.0.answer

Auggie CLI 是 Augment 的终端编程 Agent，主要用于借助上下文引擎提供理解代码库的辅助。

## faq.items.1.question

如何安装 Auggie CLI？

## faq.items.1.answer

请使用本页显示的对应平台安装命令，或按官方安装文档操作。安装完成后，运行 auggie 启动 Auggie CLI。

## faq.items.2.question

Auggie CLI 支持哪些操作系统？

## faq.items.2.answer

Auggie CLI 支持 macOS、Windows 和 Linux，并在三个平台上都通过 auggie 启动。
