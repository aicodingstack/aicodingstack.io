## answer

Pi 更像一个可编程的编码框架，而不是固定的聊天界面。开发者可以按任务选择交互模式，并用 TypeScript 组件扩展终端体验。

## introduction

Pi 不只提供交互式终端体验，还能以打印或 JSON 输出、RPC 服务及 SDK 等方式嵌入不同工作场景。开发者可用 TypeScript 扩展、Skill、主题和软件包调整这套编码框架；安装后可在 macOS、Windows 或 Linux 中运行 pi。

## faq.items.0.question

什么是 Pi？

## faq.items.0.answer

Pi 是 Earendil Inc. 的开源终端编码框架，支持交互、打印或 JSON、RPC 和 SDK 模式，并可通过 TypeScript 扩展、Skill、主题和软件包定制。

## faq.items.1.question

Pi 能做什么？

## faq.items.1.answer

根据任务选择交互式操作、适合脚本处理的打印或 JSON 输出、RPC 调用，或直接通过 SDK 集成。通过 TypeScript 扩展和可复用软件包增加行为，并用 Skill 与主题调整能力和界面体验。把 Pi 作为可检查、可扩展的开源基础，用于构建终端中的 Agent 编程工作方式。

## faq.items.2.question

## faq.items.2.answer

按照官方文档安装并完成模型配置，然后在项目目录中运行 pi，或按需使用其 RPC 与 SDK 模式。
