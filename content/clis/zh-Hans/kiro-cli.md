## answer

Kiro CLI 是 AWS 面向终端的 AI 编码工具，以规范驱动开发为核心，并提供 Agent 钩子、网络搜索和自然语言编程协助。

## introduction

Kiro CLI 让开发者从书面规范出发，在实现过程中持续以规范约束原型和生产代码。它还支持通过 Agent 钩子自动执行重复动作，并在需要外部信息时使用网络搜索；完成安装后，可在 macOS、Windows 或 Linux 的项目目录中运行 kiro-cli。

## faq.items.0.question

什么是 Kiro CLI？

## faq.items.0.answer

它适合希望让编码 Agent 依据明确规范工作，而不是只依赖临时提示词的开发者。AWS 还在这种方式中加入了终端自动化与外部信息检索能力。

## faq.items.1.question

Kiro CLI 能做什么？

## faq.items.1.answer

Kiro CLI 的核心流程是用持续有效的规范指导实现，用钩子处理重复动作，并在仓库信息不足时补充网络上下文。
