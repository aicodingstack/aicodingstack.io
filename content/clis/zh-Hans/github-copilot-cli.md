## answer

GitHub Copilot CLI 是一款终端 AI Agent，可回答问题、编写和调试代码、修改项目，并通过 GitHub 操作创建拉取请求。

## introduction

它既可作为交互式编程伙伴使用，也可在脚本和自动化中以程序化方式调用。在代码仓库中，它能调查代码、实现并调试修改、利用 GitHub 上下文，以及准备或创建拉取请求。
