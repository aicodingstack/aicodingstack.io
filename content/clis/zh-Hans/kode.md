## answer

Kode 是 shareAI Lab 的开源终端编码工具，可结合代码库上下文编辑文件、运行命令，并为 Claude Code 工作方式提供多模型选择。

## introduction

Kode 会先利用代码库上下文理解项目，再执行与现有结构相符的修改，而不是孤立地处理单个文件。它可以把文件编辑与命令执行串联在同一项开发任务中，也能在 Claude Code 风格的工作方式中切换模型；安装后可在 macOS、Windows 或 Linux 中运行 kode。
