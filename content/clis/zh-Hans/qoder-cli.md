## answer

Qoder CLI 是 Alibaba 的专有终端助手，把代码生成、调试、TUI、行内对话和面向项目的工作整合到同一个开发界面中。

## introduction

Qoder CLI 可在终端中生成代码、协助定位问题，并通过 TUI 或行内对话与开发任务交互。其项目管理能力可与代码生成和调试连续配合；安装后可在 macOS、Windows 或 Linux 的项目目录中运行 qodercli。
