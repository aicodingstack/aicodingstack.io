## answer

Cline CLI 是 Cline Bot 推出的用于从终端运行 Cline 任务的无头编程 Agent。

## introduction

借助 Cline CLI，开发者可以在无需交互式编辑器的情况下执行协作式 AI 任务，在 GitHub Actions 等场景中自动进行无头执行，并把 Cline 工作流接入 Discord 机器人和 Linear 工单。

## faq.items.0.question

Cline CLI 是什么？

## faq.items.0.answer

Cline CLI 是 Cline Bot 的终端编程 Agent，主要用于无需交互式编辑器即可执行协作式 AI 任务。

## faq.items.1.question

如何安装 Cline CLI？

## faq.items.1.answer

请使用本页显示的对应平台安装命令，或按官方安装文档操作。安装完成后，运行 cline 启动 Cline CLI。

## faq.items.2.question

Cline CLI 支持哪些操作系统？

## faq.items.2.answer

Cline CLI 支持 macOS、Windows 和 Linux，并在三个平台上都通过 cline 启动。

## faq.items.3.question

Cline CLI 如何收费？

## faq.items.3.answer

开源 CLI 本身不收许可证费用；AI 推理可能按用量收费，Enterprise 条款采用自定义方式。详情请查看价格区块。

## faq.items.4.question

Cline CLI 是开源软件吗？

## faq.items.4.answer

是。Cline CLI 采用 Apache-2.0 许可证。
