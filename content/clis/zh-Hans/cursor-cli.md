## faq.items.0.question

Cursor CLI 是什么？

## faq.items.0.answer

Cursor CLI 是 Anysphere 的终端编程 Agent，主要用于直接在终端会话中编写和修改代码。

## faq.items.1.question

如何安装 Cursor CLI？

## faq.items.1.answer

请使用本页显示的对应平台安装命令，或按官方安装文档操作。安装完成后，运行 cursor-agent 启动 Cursor CLI。

## faq.items.2.question

Cursor CLI 支持哪些操作系统？

## faq.items.2.answer

Cursor CLI 支持 macOS、Windows 和 Linux，并在三个平台上都通过 cursor-agent 启动。
