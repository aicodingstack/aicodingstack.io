## answer

Cline CLI — это headless-агент для запуска задач Cline из терминала. Разработчик — Cline Bot.

## introduction

Cline CLI позволяет из терминала выполнять совместные ИИ-задачи без интерактивного редактора, автоматизировать headless-запуск, например в GitHub Actions и соединять Cline с ботами Discord и задачами Linear.

## faq.items.0.question

Что такое Cline CLI?

## faq.items.0.answer

Cline CLI — терминальный агент программирования от Cline Bot. Он предназначен для того, чтобы выполнять совместные ИИ-задачи без интерактивного редактора.

## faq.items.1.question

Как установить Cline CLI?

## faq.items.1.answer

Используйте команду установки для своей платформы, показанную на этой странице, или следуйте официальной документации. После установки запустите Cline CLI командой cline.

## faq.items.2.question

Какие операционные системы поддерживает Cline CLI?

## faq.items.2.answer

Cline CLI доступен для macOS, Windows и Linux и запускается командой cline на каждой платформе.

## faq.items.3.question

Сколько стоит Cline CLI?

## faq.items.3.answer

CLI с открытым кодом доступен без лицензионной платы; ИИ-инференс может оплачиваться по использованию, а Enterprise имеет индивидуальные условия. Подробности смотрите в разделе цен.

## faq.items.4.question

Cline CLI имеет открытый исходный код?

## faq.items.4.answer

Да. Cline CLI доступен по лицензии Apache-2.0.
