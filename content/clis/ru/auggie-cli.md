## answer

Auggie CLI — это автономный терминальный агент на базе контекстного движка Augment. Разработчик — Augment.

## introduction

Auggie CLI позволяет из терминала использовать контекстный движок для помощи с учётом кодовой базы, выполнять автономную работу в нативном терминальном интерфейсе и соединять интерактивный TUI с автоматизированными процессами.

## faq.items.0.question

Что такое Auggie CLI?

## faq.items.0.answer

Auggie CLI — терминальный агент программирования от Augment. Он предназначен для того, чтобы использовать контекстный движок для помощи с учётом кодовой базы.

## faq.items.1.question

Как установить Auggie CLI?

## faq.items.1.answer

Используйте команду установки для своей платформы, показанную на этой странице, или следуйте официальной документации. После установки запустите Auggie CLI командой auggie.

## faq.items.2.question

Какие операционные системы поддерживает Auggie CLI?

## faq.items.2.answer

Auggie CLI доступен для macOS, Windows и Linux и запускается командой auggie на каждой платформе.

## faq.items.3.question
