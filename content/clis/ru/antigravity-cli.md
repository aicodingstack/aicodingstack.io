## answer

Antigravity CLI — это терминальная оркестрация агентов Antigravity. Разработчик — Google.

## introduction

Antigravity CLI позволяет из терминала запускать и отслеживать агентов Antigravity, координировать субагентов, правки нескольких файлов, инструменты, MCP и skills и работать локально или через документированную поддержку SSH.

## faq.items.0.question

Что такое Antigravity CLI?

## faq.items.0.answer

Antigravity CLI — терминальный агент программирования от Google. Он предназначен для того, чтобы запускать и отслеживать агентов Antigravity из терминала.

## faq.items.1.question

Как установить Antigravity CLI?

## faq.items.1.answer

Используйте команду установки для своей платформы, показанную на этой странице, или следуйте официальной документации. После установки запустите Antigravity CLI командой agy.

## faq.items.2.question

Какие операционные системы поддерживает Antigravity CLI?

## faq.items.2.answer

Antigravity CLI доступен для macOS, Windows и Linux и запускается командой agy на каждой платформе.
