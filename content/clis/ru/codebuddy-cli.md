## answer

CodeBuddy CLI — это терминальный ИИ-редактор для генерации кода, отладки и процессов разработки. Разработчик — Tencent.

## introduction

CodeBuddy CLI позволяет из терминала создавать и изменять код, отлаживать код в процессах с поддержкой ИИ и работать через нативный TUI или встроенный чат.

## faq.items.0.question

Что такое CodeBuddy CLI?

## faq.items.0.answer

CodeBuddy CLI — терминальный агент программирования от Tencent. Он предназначен для того, чтобы создавать и изменять код из терминала.

## faq.items.1.question

Как установить CodeBuddy CLI?

## faq.items.1.answer

Используйте команду установки для своей платформы, показанную на этой странице, или следуйте официальной документации. После установки запустите CodeBuddy CLI командой codebuddy.

## faq.items.2.question

Какие операционные системы поддерживает CodeBuddy CLI?

## faq.items.2.answer

CodeBuddy CLI доступен для macOS, Windows и Linux и запускается командой codebuddy на каждой платформе.
