## answer

Amazon Q Developer CLI — это агентный CLI-помощник, который понимает кодовую базу и выполняет задачи в естественном диалоге. Разработчик — AWS.

## introduction

Amazon Q Developer CLI позволяет из терминала понимать репозиторий и помогать с учётом контекста кода, выполнять запросы через адаптивный диалог и использовать команду q в локальной среде разработки.

## faq.items.0.question

Что такое Amazon Q Developer CLI?

## faq.items.0.answer

Amazon Q Developer CLI — терминальный агент программирования от AWS. Он предназначен для того, чтобы понимать репозиторий и помогать с учётом контекста кода.
