## answer

Qwen Code — открытый агент для пользователей терминала, которым нужно изучать большую кодовую базу, изменять файлы, выполнять команды и выбирать подключение Qwen или совместимое с OpenAI.

## introduction

Qwen Code учитывает контекст большого репозитория перед тем, как в рамках одной задачи изменять файлы и выполнять необходимые команды. Он может использовать Qwen или сервисы с интерфейсом, совместимым с OpenAI. После установки и настройки модели qwen запускается в проекте под macOS, Windows или Linux.
