## answer

GitHub Copilot CLI — терминальный ИИ-агент, который отвечает на вопросы, пишет и отлаживает код, изменяет проекты и работает с GitHub для создания pull request.

## introduction

Его можно использовать как интерактивного партнёра по программированию или вызывать программно в сценариях и автоматизации. В репозитории он исследует код, реализует и отлаживает изменения, использует контекст GitHub и подготавливает или создаёт pull request.

## capabilities.items.0.title

Отвечать с учётом контекста проекта

## capabilities.items.0.description

Задавайте вопросы о структуре репозитория, деталях реализации или незнакомых ошибках и получайте ответы, основанные на текущем проекте.

## capabilities.items.1.title

Писать, отлаживать и изменять код

## capabilities.items.1.description

Поручайте агенту реализовывать функции, диагностировать сбои и редактировать файлы проекта непосредственно из терминала.

## capabilities.items.2.title

Работать с GitHub и pull request

## capabilities.items.2.description

Используйте контекст и процессы GitHub, чтобы проверять активность репозитория и подготавливать или создавать pull request из командной строки.
