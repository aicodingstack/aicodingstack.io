## answer

Kimi Code CLI — терминальный агент Moonshot AI для изучения репозиториев, редактирования файлов, выполнения команд, работы с инструментами MCP и общих процессов с расширением VS Code.

## introduction

Разработчик может начать в локальном репозитории и поручить Kimi изучить нужный код, внести изменения и применить необходимые инструменты, не ограничивая сеанс советами из чата. Когда удобнее работать в редакторе, ту же задачу можно продолжить в расширении Kimi Code для VS Code.

## capabilities.items.0.description

Kimi перемещается по репозиторию, исследует нужные файлы и применяет правки с учётом найденного контекста.

Команды и инструменты MCP

## capabilities.items.1.description

Он выполняет локальные команды и подключает инструменты MCP, выходя за рамки простых предложений кода.

## capabilities.items.2.title

Общие процессы с расширением VS Code

## capabilities.items.2.description

CLI и расширение Kimi Code для VS Code поддерживают непрерывную работу между терминалом и редактором.

## faq.items.0.question

Что такое Kimi Code CLI?

## faq.items.0.answer

Инструмент предназначен для разработчиков, которым нужен агент для работы с локальным репозиторием из терминала и возможность при необходимости перейти в VS Code. Moonshot AI предоставляет CLI и связанное расширение.

## faq.items.1.question

Каковы основные возможности Kimi Code CLI?

## faq.items.1.answer

Процесс объединяет изменения с учетом репозитория, локальные команды и инструменты MCP, позволяя выбирать терминал или редактор в зависимости от задачи.
