## answer

Cursor CLI — это ИИ-агент командной строки для написания, проверки и изменения кода. Разработчик — Anysphere.

## faq.items.0.question

Что такое Cursor CLI?

## faq.items.0.answer

Cursor CLI — терминальный агент программирования от Anysphere. Он предназначен для того, чтобы писать и изменять код прямо из терминала.

## faq.items.1.question

Как установить Cursor CLI?

## faq.items.1.answer

Используйте команду установки для своей платформы, показанную на этой странице, или следуйте официальной документации. После установки запустите Cursor CLI командой cursor-agent.

## faq.items.2.question

Какие операционные системы поддерживает Cursor CLI?

## faq.items.2.answer

Cursor CLI доступен для macOS, Windows и Linux и запускается командой cursor-agent на каждой платформе.
