## answer

Cursor CLI adalah agen baris perintah berbasis AI untuk menulis, meninjau, dan mengubah kode. Produk ini berasal dari Anysphere.

## introduction

Cursor CLI memungkinkan Anda dari terminal untuk menulis dan mengubah kode langsung dari terminal, meninjau kode dengan bantuan AI, dan menggunakan model canggih dari beberapa penyedia.
