## answer

GitHub Copilot CLI adalah agen AI terminal yang menjawab pertanyaan, menulis dan men-debug kode, mengubah proyek, serta bekerja dengan GitHub untuk membuat pull request.

## introduction

Alat ini dapat digunakan sebagai rekan pemrograman interaktif atau dijalankan secara programatis dalam skrip dan otomatisasi. Dari repositori, alat ini dapat memeriksa kode, menerapkan dan men-debug perubahan, memakai konteks GitHub, serta menyiapkan atau membuat pull request.
