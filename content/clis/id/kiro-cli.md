## answer

Kiro CLI adalah alat coding AI untuk terminal dari AWS yang berpusat pada pengembangan berbasis spesifikasi serta dilengkapi hook agen, pencarian web, dan bantuan bahasa alami.

## introduction

Kiro CLI memulai pekerjaan dari spesifikasi tertulis yang tetap menjadi acuan sejak prototipe hingga kode produksi. Hook agen dapat memicu tindakan berulang, sedangkan pencarian web menyediakan konteks eksternal saat diperlukan. Setelah dipasang, kiro-cli dijalankan dari direktori proyek di macOS, Windows, atau Linux.
