## answer

Kimi Code CLI adalah agen terminal Moonshot AI untuk menjelajahi repositori, mengedit berkas, menjalankan perintah, menggunakan alat MCP, dan berbagi alur kerja dengan ekstensi VS Code.

## introduction

Pengembang dapat memulai dari repositori lokal dan membiarkan Kimi memeriksa kode terkait, menerapkan perubahan, serta menggunakan alat yang dibutuhkan tanpa membatasi sesi pada saran chat. Saat tampilan editor lebih sesuai, pekerjaan yang sama dapat dilanjutkan di ekstensi Kimi Code untuk VS Code.

## faq.items.0.question

Apa itu Kimi Code CLI?

## faq.items.0.answer

Alat ini ditujukan bagi pengembang yang ingin agen bertindak pada repositori lokal dari terminal sekaligus memiliki jalur ke VS Code. Moonshot AI menyediakan CLI dan ekstensi editor terkait.

## faq.items.1.answer

Alurnya menghubungkan perubahan yang memahami repositori dengan perintah lokal dan alat MCP, lalu memungkinkan perpindahan antara terminal dan editor sesuai tugas.
