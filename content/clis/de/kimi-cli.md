## answer

Kimi Code CLI ist der Terminal-Coding-Agent von Moonshot AI für Repository-Erkundung, Dateibearbeitung, Befehlsausführung, MCP-Werkzeuge und gemeinsame Arbeitsabläufe mit seiner VS-Code-Erweiterung.

## introduction

Entwickler können in einem lokalen Repository beginnen und Kimi den relevanten Code untersuchen, Änderungen vornehmen und benötigte Werkzeuge ausführen lassen, statt nur Vorschläge aus einem Chat zu erhalten. Wenn eine Editoransicht geeigneter ist, lässt sich dieselbe Arbeit in der Kimi-Code-Erweiterung für VS Code fortsetzen.

## capabilities.items.0.title

Repository-Erkundung und Dateibearbeitung

## capabilities.items.0.description

Kimi navigiert durch ein Repository, untersucht relevante Dateien und wendet Änderungen im gefundenen Codekontext an.

## capabilities.items.1.title

Befehle und MCP-Werkzeuge

## capabilities.items.1.description

Der Agent führt lokale Befehle aus und bindet MCP-Werkzeuge ein, statt sich auf Codevorschläge zu beschränken.

## capabilities.items.2.title

Gemeinsame Workflows mit der VS-Code-Erweiterung

## capabilities.items.2.description

CLI und Kimi-Code-Erweiterung für VS Code unterstützen einen zusammenhängenden Wechsel zwischen Terminal und Editor.

## faq.items.0.question

Was ist Kimi Code CLI?

## faq.items.0.answer

Das Werkzeug richtet sich an Entwickler, die einen Agenten im Terminal direkt auf ein lokales Repository ansetzen und bei Bedarf zu VS Code wechseln möchten. Moonshot AI stellt dafür sowohl die CLI als auch die zugehörige Editor-Erweiterung bereit.

## faq.items.1.question

Was sind die Kernfunktionen von Kimi Code CLI?

## faq.items.1.answer

Der Arbeitsablauf verbindet repositorybezogene Änderungen mit lokalen Befehlen und MCP-Werkzeugen und lässt je nach Aufgabe einen Wechsel zwischen Terminal und Editor zu.

## faq.items.2.question

Wie installiere und starte ich Kimi Code CLI?

## faq.items.2.answer

Wählen Sie die auf dieser Seite gezeigte Methode für Ihr Betriebssystem, folgen Sie den offiziellen Einrichtungshinweisen und beginnen Sie im Repository, das Kimi untersuchen soll.

## faq.items.3.question

Welche Plattformen unterstützt Kimi Code CLI?

## faq.items.3.answer

Es unterstützt macOS, Windows und Linux.
