## answer

Antigravity CLI ist terminalorientierte Agenten-Orchestrierung für Antigravity. Anbieter ist Google.

## introduction

Antigravity CLI ruft Antigravity-Agenten im Terminal auf und überwacht sie, koordiniert Subagenten, Mehrdatei-Änderungen, Tools, MCP und Skills und unterstützt lokale sowie dokumentierte SSH-Arbeitsabläufe.

## faq.items.0.question

Was ist Antigravity CLI?

## faq.items.0.answer

Antigravity CLI ist ein Coding-Agent für das Terminal von Google. Sein Schwerpunkt ist: Antigravity-Agenten im Terminal aufrufen und überwachen.

## faq.items.1.question

Wie installiere ich Antigravity CLI?

## faq.items.1.answer

Verwenden Sie den auf dieser Seite gezeigten plattformspezifischen Installationsbefehl oder folgen Sie der offiziellen Installationsdokumentation. Danach starten Sie Antigravity CLI mit agy.

## faq.items.2.question

Welche Betriebssysteme unterstützt Antigravity CLI?

## faq.items.2.answer

Antigravity CLI ist für macOS, Windows und Linux verfügbar und wird auf jeder Plattform mit agy gestartet.

## faq.items.3.question

Was kostet Antigravity CLI?

## faq.items.3.answer

Antigravity CLI bietet eine kostenlose Individual-Option, kostenpflichtige Google-AI-Stufen und eine nutzungsabhängige Organisationsoption. Aktuelle Bedingungen stehen im Preisabschnitt.
