## answer

GitHub Copilot CLI ist ein KI-Agent für das Terminal, der Fragen beantwortet, Code schreibt und debuggt, Projekte ändert und über GitHub Pull Requests erstellt.

## introduction

Er lässt sich als interaktiver Coding-Partner oder programmgesteuert in Skripten und Automatisierungen einsetzen. In einem Repository kann er Code untersuchen, Änderungen implementieren und debuggen, GitHub-Kontext nutzen sowie Pull Requests vorbereiten oder erstellen.

## capabilities.items.0.title

Fragen im Projektkontext beantworten

## capabilities.items.0.description

Fragen Sie nach Repository-Struktur, Implementierungsdetails oder unbekannten Fehlern und erhalten Sie Antworten, die sich auf das aktuelle Projekt beziehen.

## capabilities.items.1.title

Code schreiben, debuggen und ändern

## capabilities.items.1.description

Lassen Sie den Agenten Funktionen implementieren, Fehler untersuchen und Dateien direkt aus dem Terminal heraus bearbeiten.

## capabilities.items.2.title

Mit GitHub und Pull Requests arbeiten

## capabilities.items.2.description

Nutzen Sie GitHub-Kontext und Workflows, um Repository-Aktivitäten zu prüfen und Pull Requests vorzubereiten oder zu erstellen.

## faq.items.0.question

Was ist GitHub Copilot CLI?

## faq.items.0.answer

Es ist der terminalnative Coding-Agent von GitHub zum Untersuchen von Codebasen, Implementieren von Änderungen, Debuggen von Problemen und Abschließen von GitHub-Workflows.

## faq.items.1.question

Was sind die Kernfunktionen von GitHub Copilot CLI?

## faq.items.1.answer

Er kann Fragen zur Codebasis beantworten, Code schreiben und debuggen, Projektdateien ändern, mit GitHub arbeiten und Pull Requests erstellen.

## faq.items.2.question

Kann GitHub Copilot CLI interaktiv und programmgesteuert arbeiten?

## faq.items.2.answer

Ja. Sie können ihn interaktiv im Terminal verwenden oder für wiederholbare Skripte, Automatisierungen und Integrationen programmgesteuert aufrufen.

## faq.items.3.question

Welche Plattformen unterstützt GitHub Copilot CLI?

## faq.items.3.answer

Es unterstützt macOS, Windows und Linux.

## faq.items.4.question

Wo finde ich die Preise für GitHub Copilot CLI?

## faq.items.4.answer

Auf der offiziellen Preisseite finden Sie Verfügbarkeit der Pläne und Abrechnungsdetails.
