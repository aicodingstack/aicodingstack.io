## answer

CodeBuddy CLI ist ein KI-gestützter Terminal-Editor für Codegenerierung, Debugging und Entwicklungsabläufe. Anbieter ist Tencent.

## introduction

Mit CodeBuddy CLI lassen sich im Terminal Code erzeugen und ändern, Code mit KI-gestützten Abläufen debuggen und über native TUI oder Inline-Chat arbeiten.

## faq.items.0.question

Was ist CodeBuddy CLI?

## faq.items.0.answer

CodeBuddy CLI ist ein Coding-Agent für das Terminal von Tencent. Sein Schwerpunkt ist: Code im Terminal erzeugen und ändern.

## faq.items.1.question

Wie installiere ich CodeBuddy CLI?

## faq.items.1.answer

Verwenden Sie den auf dieser Seite gezeigten plattformspezifischen Installationsbefehl oder folgen Sie der offiziellen Installationsdokumentation. Danach starten Sie CodeBuddy CLI mit codebuddy.

## faq.items.2.question

Welche Betriebssysteme unterstützt CodeBuddy CLI?

## faq.items.2.answer

CodeBuddy CLI ist für macOS, Windows und Linux verfügbar und wird auf jeder Plattform mit codebuddy gestartet.

## faq.items.3.question

Was kostet CodeBuddy CLI?

## faq.items.3.answer

CodeBuddy CLI bietet eine kostenlose Option sowie kostenpflichtige Individual-, Team- und Enterprise-Pläne. Aktuelle Bedingungen stehen im Preisabschnitt.

## faq.items.4.question

Ist CodeBuddy CLI Open Source?

## faq.items.4.answer

Nein. CodeBuddy CLI ist proprietäre Software.
