## answer

Qwen Code ist ein quelloffener Repository-Agent für Terminalnutzer, die große Codebasen untersuchen, Dateien ändern, Befehle ausführen und zwischen Qwen- und OpenAI-kompatiblen Modellverbindungen wählen möchten.

## introduction

Qwen Code analysiert den Kontext großer Codebasen, bevor es im selben Arbeitsauftrag Dateien ändert und erforderliche Befehle ausführt. Neben Qwen lassen sich Modelle über OpenAI-kompatible Schnittstellen verbinden. Nach Installation und Modellkonfiguration wird qwen im Projektverzeichnis unter macOS, Windows oder Linux gestartet.

## faq.items.0.question

Was ist Qwen Code?

## faq.items.0.answer

Qwen Code ist ein quelloffener Terminal-Coding-Agent von Alibaba, der große Codebasen versteht, Dateien bearbeitet und Befehle ausführt sowie Qwen- und OpenAI-kompatible Modelle anbinden kann.

## faq.items.2.answer
