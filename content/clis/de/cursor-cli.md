## answer

Cursor CLI ist ein KI-gestützter Kommandozeilen-Agent zum Schreiben, Prüfen und Ändern von Code. Anbieter ist Anysphere.

## introduction

Mit Cursor CLI lassen sich im Terminal Code direkt in einer Terminalsitzung schreiben und ändern, Code mit KI-Unterstützung prüfen und Frontier-Modelle mehrerer Anbieter nutzen.

## faq.items.0.question

Was ist Cursor CLI?

## faq.items.0.answer

Cursor CLI ist ein Coding-Agent für das Terminal von Anysphere. Sein Schwerpunkt ist: Code direkt in einer Terminalsitzung schreiben und ändern.

## faq.items.1.question

Wie installiere ich Cursor CLI?

## faq.items.1.answer

Verwenden Sie den auf dieser Seite gezeigten plattformspezifischen Installationsbefehl oder folgen Sie der offiziellen Installationsdokumentation. Danach starten Sie Cursor CLI mit cursor-agent.

## faq.items.2.question

Welche Betriebssysteme unterstützt Cursor CLI?

## faq.items.2.answer

Cursor CLI ist für macOS, Windows und Linux verfügbar und wird auf jeder Plattform mit cursor-agent gestartet.

## faq.items.3.question

Was kostet Cursor CLI?

## faq.items.3.answer

Cursor CLI bietet eine kostenlose Option sowie kostenpflichtige Individual-, Team- und Enterprise-Pläne. Aktuelle Bedingungen stehen im Preisabschnitt.
