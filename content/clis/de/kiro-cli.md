## answer

Kiro CLI ist ein KI-Coding-Werkzeug von AWS für das Terminal, das spezifikationsgetriebene Entwicklung mit Agent Hooks, Websuche und Unterstützung durch natürliche Sprache verbindet.

## introduction

Mit Kiro CLI beginnt die Arbeit bei einer schriftlichen Spezifikation, die vom Prototyp bis zum produktiven Code als verbindlicher Bezugspunkt dient. Wiederkehrende Aktionen lassen sich über Agent Hooks auslösen, während die Websuche bei Bedarf externen Kontext liefert. Nach der Installation wird kiro-cli im Projektverzeichnis unter macOS, Windows oder Linux gestartet.

## capabilities.items.0.title

Spezifikationsgetriebene Entwicklung

## capabilities.items.0.description

Anforderungen und Entwurf werden zuerst als Spezifikation festgehalten und anschließend als Maßstab für Prototypen, Codeänderungen und Produktionsziele verwendet.

## capabilities.items.1.title

Agent Hooks und Websuche

## capabilities.items.1.description

Agent Hooks lösen wiederholbare Aktionen aus; die Websuche ergänzt externe Hintergrundinformationen, wenn sie für eine Aufgabe benötigt werden.

## capabilities.items.2.title

Coding-Unterstützung in natürlicher Sprache

## capabilities.items.2.description

Entwicklungsaufgaben lassen sich in natürlicher Sprache beschreiben und anschließend in derselben Terminalsitzung am lokalen Projekt prüfen, bearbeiten und verifizieren.

## faq.items.0.question

Was ist Kiro CLI?

## faq.items.0.answer

Das Werkzeug ist für Entwickler gedacht, die einen Coding-Agenten nach einer ausdrücklichen Spezifikation arbeiten lassen möchten, statt sich nur auf spontane Prompts zu verlassen. AWS ergänzt diesen Ansatz um Terminalautomatisierung und externe Recherche.

## faq.items.1.question

Was kann Kiro CLI?

## faq.items.1.answer

Kiro CLI verbindet eine dauerhaft gültige Spezifikation mit der Implementierung, überlässt wiederkehrende Aktionen den Hooks und ergänzt Webkontext, wenn das Repository allein nicht ausreicht.

## faq.items.2.question

Wie beginne ich mit Kiro CLI?

## faq.items.2.answer

Folgen Sie der offiziellen Installationsanleitung für Ihr Betriebssystem und starten Sie anschließend kiro-cli im Terminal des Projektverzeichnisses.

## faq.items.3.question

Welche Betriebssysteme unterstützt Kiro CLI?

## faq.items.3.answer

Kiro CLI unterstützt macOS, Windows und Linux. Prüfen Sie vor der Installation die plattformspezifischen Anforderungen in der offiziellen Dokumentation.

## faq.items.4.question

Wie sind Lizenz und Preise von Kiro CLI geregelt?

## faq.items.4.answer

Kiro CLI ist ein proprietäres Produkt mit kostenlosen und kostenpflichtigen Nutzungsmöglichkeiten. Leistungsumfang und Grenzen stehen auf der offiziellen Preisseite.
