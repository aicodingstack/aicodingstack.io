## answer

Auggie CLI ist ein autonomer Terminal-Agent mit der Context Engine von Augment. Anbieter ist Augment.

## introduction

Mit Auggie CLI lassen sich im Terminal die Context Engine für codebasisspezifische Hilfe nutzen, autonome Arbeit in einer nativen Terminaloberfläche ausführen und interaktive TUI-Nutzung mit automatisierten Abläufen verbinden.

## faq.items.0.question

Was ist Auggie CLI?

## faq.items.0.answer

Auggie CLI ist ein Coding-Agent für das Terminal von Augment. Sein Schwerpunkt ist: die Context Engine für codebasisspezifische Hilfe nutzen.

## faq.items.1.question

Wie installiere ich Auggie CLI?

## faq.items.1.answer

Verwenden Sie den auf dieser Seite gezeigten plattformspezifischen Installationsbefehl oder folgen Sie der offiziellen Installationsdokumentation. Danach starten Sie Auggie CLI mit auggie.

## faq.items.2.question

Welche Betriebssysteme unterstützt Auggie CLI?

## faq.items.2.answer

Auggie CLI ist für macOS, Windows und Linux verfügbar und wird auf jeder Plattform mit auggie gestartet.

## faq.items.3.question
