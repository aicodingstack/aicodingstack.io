## answer

Qoder CLI ist Alibabas proprietärer Terminalassistent, der Codegenerierung, Fehlersuche, TUI, Inline-Chat und projektbezogene Arbeit in einer Entwicklungsoberfläche zusammenführt.

## introduction

Qoder CLI generiert Code im Terminal, unterstützt die Fehlersuche und ermöglicht die Interaktion mit einer Entwicklungsaufgabe über TUI oder Inline-Chat. Das Projektmanagement schließt direkt an Codegenerierung und Debugging an. Nach der Installation wird qodercli im Projektverzeichnis unter macOS, Windows oder Linux gestartet.
