## answer

Claude Code ist ein Terminal-Assistent, der Codebasen versteht und Aufgaben in natürlicher Sprache ausführt. Anbieter ist Anthropic.

## introduction

Mit Claude Code lassen sich im Terminal Codebasen im Repository-Kontext verstehen und erklären, Coding-Aufgaben und Git-Workflows ausführen und Terminalarbeit über MCP-Integrationen erweitern.

## faq.items.0.question

Was ist Claude Code?

## faq.items.0.answer

Claude Code ist ein Coding-Agent für das Terminal von Anthropic. Sein Schwerpunkt ist: Codebasen im Repository-Kontext verstehen und erklären.

## faq.items.1.question

Wie installiere ich Claude Code?

## faq.items.1.answer

Verwenden Sie den auf dieser Seite gezeigten plattformspezifischen Installationsbefehl oder folgen Sie der offiziellen Installationsdokumentation. Danach starten Sie Claude Code mit claude.

## faq.items.2.question

Welche Betriebssysteme unterstützt Claude Code?

## faq.items.2.answer

Claude Code ist für macOS, Windows und Linux verfügbar und wird auf jeder Plattform mit claude gestartet.

## faq.items.3.question

Was kostet Claude Code?

## faq.items.3.answer

Claude Code ist in Individual-Abonnements sowie in Team- und Enterprise-Plänen verfügbar. Aktuelle Bedingungen stehen im Preisabschnitt.
