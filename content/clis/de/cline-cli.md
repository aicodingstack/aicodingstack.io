## answer

Cline CLI ist ein Headless-Coding-Agent für Cline-Aufgaben im Terminal. Anbieter ist Cline Bot.

## introduction

Mit Cline CLI lassen sich im Terminal kollaborative KI-Aufgaben ohne interaktiven Editor ausführen, headless-Ausführung etwa in GitHub Actions automatisieren und Cline-Abläufe mit Discord-Bots und Linear-Tickets verbinden.

## faq.items.0.question

Was ist Cline CLI?

## faq.items.0.answer

Cline CLI ist ein Coding-Agent für das Terminal von Cline Bot. Sein Schwerpunkt ist: kollaborative KI-Aufgaben ohne interaktiven Editor ausführen.

## faq.items.1.question

Wie installiere ich Cline CLI?

## faq.items.1.answer

Verwenden Sie den auf dieser Seite gezeigten plattformspezifischen Installationsbefehl oder folgen Sie der offiziellen Installationsdokumentation. Danach starten Sie Cline CLI mit cline.

## faq.items.2.question

Welche Betriebssysteme unterstützt Cline CLI?

## faq.items.2.answer

Cline CLI ist für macOS, Windows und Linux verfügbar und wird auf jeder Plattform mit cline gestartet.

## faq.items.3.question

Was kostet Cline CLI?

## faq.items.3.answer

Die Open-Source-CLI ist ohne Lizenzgebühr verfügbar; KI-Inferenz kann nutzungsabhängig abgerechnet werden, Enterprise-Bedingungen sind individuell. Details stehen im Preisabschnitt.

## faq.items.4.question

## faq.items.4.answer
