## faq.items.0.question

Was ist Grok Build?

## faq.items.0.answer

Grok Build ist der quelloffene Terminal-Coding-Agent von xAI zum Erkunden von Repositories, Bearbeiten von Code, Ausführen von Befehlen und Erledigen durchgängiger Entwicklungsaufgaben. Er ist für die direkte Arbeit an einem Projekt aus einer Terminalsitzung heraus konzipiert.

## faq.items.1.question

Was sind die Kernfunktionen von Grok Build?

## faq.items.1.answer

Grok Build durchsucht ein Repository und prüft relevante Dateien, damit geplante Änderungen den aktuellen Code berücksichtigen. Der Agent kann Code bearbeiten und Terminalbefehle ausführen, um Implementierung und lokale Prüfung zu verbinden. Eine Entwicklungsaufgabe kann von der Erkundung über die Bearbeitung bis zur Befehlsausführung durchgängig bearbeitet werden.
