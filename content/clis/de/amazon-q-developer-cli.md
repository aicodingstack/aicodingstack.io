## answer

Amazon Q Developer CLI ist ein agentischer CLI-Assistent, der Codebasen versteht und Aufgaben im natürlichen Dialog ausführt. Anbieter ist AWS.

## introduction

Mit Amazon Q Developer CLI lassen sich im Terminal ein Repository erfassen und mit Codekontext unterstützen, angeforderte Aufgaben im adaptiven Sprachdialog ausführen und den Befehl q in der lokalen Entwicklungsumgebung verwenden.

## faq.items.0.question

Was ist Amazon Q Developer CLI?

## faq.items.0.answer

Amazon Q Developer CLI ist ein Coding-Agent für das Terminal von AWS. Sein Schwerpunkt ist: ein Repository erfassen und mit Codekontext unterstützen.

## faq.items.1.question

Wie installiere ich Amazon Q Developer CLI?

## faq.items.1.answer

Verwenden Sie den auf dieser Seite gezeigten plattformspezifischen Installationsbefehl oder folgen Sie der offiziellen Installationsdokumentation. Danach starten Sie Amazon Q Developer CLI mit q.

## faq.items.2.question

Welche Betriebssysteme unterstützt Amazon Q Developer CLI?

## faq.items.2.answer

Amazon Q Developer CLI ist für macOS, Windows und Linux verfügbar und wird auf jeder Plattform mit q gestartet.

Amazon Q Developer CLI bietet eine kostenlose Option und ein kostenpflichtiges Abonnement pro Nutzer. Aktuelle Grenzen und Bedingungen stehen im Preisabschnitt und in der offiziellen Preisquelle.
