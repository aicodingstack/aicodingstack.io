## faq.items.0.question

Was ist Kilo Code CLI?

## faq.items.0.answer

Kilo Code CLI ist Kilos Terminaloberfläche für KI-gestützte Programmierung. Sie interpretiert natürliche Sprache als Aufgaben zur Codeerzeugung, Fehlersuche und weiteren Entwicklung.
