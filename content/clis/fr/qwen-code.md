## answer

Qwen Code est un agent de dépôt open source pour étudier une grande base de code, modifier des fichiers, exécuter des commandes et choisir une connexion Qwen ou compatible OpenAI.

## introduction

Qwen Code s’appuie sur le contexte d’un grand dépôt avant de modifier des fichiers et d’exécuter les commandes nécessaires dans la même tâche. Il peut utiliser Qwen ou un service exposant une interface compatible OpenAI. Une fois l’installation et le modèle configurés, qwen s’exécute dans le projet sous macOS, Windows ou Linux.

## faq.items.0.question

Qu’est-ce que Qwen Code ?

## faq.items.0.answer

Qwen Code est un Agent de programmation en terminal open source d’Alibaba, conçu pour comprendre de grands dépôts, modifier des fichiers et exécuter des commandes, avec une connexion aux modèles Qwen ou compatibles OpenAI.

## faq.items.1.question

Que permet de faire Qwen Code ?

## faq.items.1.answer

La structure du dépôt et le contexte pertinent sont analysés avant toute modification, afin de raisonner sur l’ensemble du projet plutôt que sur un fichier isolé. Les fichiers sont modifiés dans la même tâche de terminal, puis la compilation, les tests ou d’autres commandes poursuivent l’implémentation et la vérification. ## faq.items.2.answer

Installez Qwen Code, configurez l’accès au modèle selon la documentation officielle, puis exécutez qwen dans le dossier du projet local.
