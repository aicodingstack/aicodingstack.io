## answer

Amazon Q Developer CLI est un assistant CLI agentique qui comprend le code et exécute des tâches par dialogue naturel. Ce produit est proposé par AWS.

## introduction

Amazon Q Developer CLI permet depuis le terminal de comprendre un dépôt et aider avec le contexte du code, exécuter les tâches demandées par un dialogue adaptatif et utiliser la commande q dans l’environnement local.
