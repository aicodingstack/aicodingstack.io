## answer

Antigravity CLI est une orchestration d’agents Antigravity centrée sur le terminal. Ce produit est proposé par Google.

## introduction

Antigravity CLI permet depuis le terminal d’appeler et surveiller des agents Antigravity, coordonner sous-agents, modifications multifichiers, outils, MCP et skills et travailler localement ou via la prise en charge SSH documentée.

## faq.items.0.question

Qu’est-ce que Antigravity CLI ?

## faq.items.0.answer

Antigravity CLI est un agent de programmation en terminal proposé par Google. Il est conçu pour appeler et surveiller des agents Antigravity.

## faq.items.1.question

Comment installer Antigravity CLI ?

## faq.items.1.answer

Utilisez la commande d’installation propre à votre plateforme affichée sur cette page ou suivez la documentation officielle. Après l’installation, lancez Antigravity CLI avec agy.

## faq.items.2.question

Quels systèmes d’exploitation Antigravity CLI prend-il en charge ?

## faq.items.2.answer

Antigravity CLI est disponible pour macOS, Windows et Linux, avec la commande agy sur chaque plateforme.

## faq.items.3.question

Combien coûte Antigravity CLI ?

## faq.items.3.answer

Antigravity CLI propose une option individuelle gratuite, des niveaux Google AI payants et une option Organization à l’usage. Consultez la section tarifaire.
