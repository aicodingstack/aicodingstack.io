## answer

Qoder CLI est l’assistant propriétaire d’Alibaba qui réunit génération de code, débogage, TUI, discussion intégrée et travail orienté projet dans une même interface terminal.

## introduction

Qoder CLI génère du code dans le terminal, aide à diagnostiquer les problèmes et permet d’interagir avec la tâche au moyen d’une TUI ou d’un chat intégré. La gestion de projet se poursuit directement avec la génération de code et le débogage. Après installation, qodercli s’exécute dans le dossier du projet sous macOS, Windows ou Linux.
