## answer

Claude Code est un assistant en terminal qui comprend le code et exécute des tâches en langage naturel. Ce produit est proposé par Anthropic.

## introduction

Claude Code permet depuis le terminal de comprendre et expliquer le code avec le contexte du dépôt, exécuter des tâches et gérer des flux Git et étendre le terminal grâce aux intégrations MCP.

## faq.items.1.question
