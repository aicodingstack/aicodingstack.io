## answer

Auggie CLI est un agent autonome en terminal alimenté par le moteur de contexte d’Augment. Ce produit est proposé par Augment.

## introduction

Auggie CLI permet depuis le terminal d’exploiter le moteur de contexte pour une assistance liée au code, exécuter un travail autonome dans une interface terminal native et relier la TUI interactive aux flux automatisés.

## faq.items.0.question

Qu’est-ce que Auggie CLI ?

## faq.items.0.answer

Auggie CLI est un agent de programmation en terminal proposé par Augment. Il est conçu pour exploiter le moteur de contexte pour une assistance liée au code.

## faq.items.1.question

Comment installer Auggie CLI ?

## faq.items.1.answer

Utilisez la commande d’installation propre à votre plateforme affichée sur cette page ou suivez la documentation officielle. Après l’installation, lancez Auggie CLI avec auggie.

## faq.items.2.question

Quels systèmes d’exploitation Auggie CLI prend-il en charge ?

## faq.items.2.answer

Auggie CLI est disponible pour macOS, Windows et Linux, avec la commande auggie sur chaque plateforme.
