## answer

Amp est un agent de programmation avancé pour le raisonnement autonome, la modification de code et les tâches complexes. Ce produit est proposé par Sourcegraph.

## introduction

Amp permet depuis le terminal de raisonner de façon autonome sur le code et le résultat demandé, modifier le code et mener des tâches complexes et utiliser le même agent en CLI et dans les éditeurs compatibles.

## faq.items.0.question

Qu’est-ce que Amp ?

## faq.items.0.answer

Amp est un agent de programmation en terminal proposé par Sourcegraph. Il est conçu pour raisonner de façon autonome sur le code et le résultat demandé.

## faq.items.1.question

Comment installer Amp ?

## faq.items.1.answer

Utilisez la commande d’installation propre à votre plateforme affichée sur cette page ou suivez la documentation officielle. Après l’installation, lancez Amp avec amp.

## faq.items.2.question

Quels systèmes d’exploitation Amp prend-il en charge ?

## faq.items.2.answer

Amp est disponible pour macOS, Windows et Linux, avec la commande amp sur chaque plateforme.

## faq.items.3.question

## faq.items.3.answer

Amp propose des abonnements mensuels, un accès facturé à l’usage et une option Enterprise. Consultez la section tarifaire pour les conditions actuelles.
