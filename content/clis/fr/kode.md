## answer

Kode est un outil de programmation en terminal open source de shareAI Lab qui modifie le code avec le contexte du dépôt, exécute des commandes et permet de choisir plusieurs modèles dans une expérience proche de Claude Code.

## introduction

Kode comprend le projet à partir du contexte de l’ensemble du code et produit des modifications adaptées à la structure existante, au lieu de traiter chaque fichier isolément. L’édition et l’exécution de commandes s’enchaînent dans une même tâche, avec la possibilité de changer de modèle dans une expérience proche de Claude Code. Après installation, kode fonctionne sous macOS, Windows ou Linux.
