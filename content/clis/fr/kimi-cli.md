## answer

Kimi Code CLI est l’agent de terminal de Moonshot AI pour explorer les dépôts, modifier les fichiers, exécuter des commandes, utiliser des outils MCP et partager des flux avec son extension VS Code.

## introduction

Un développeur peut partir d’un dépôt local et laisser Kimi examiner le code pertinent, appliquer des modifications et utiliser les outils nécessaires, sans limiter la session à des conseils de conversation. Lorsqu’une vue d’éditeur est préférable, le même travail se poursuit dans l’extension Kimi Code pour VS Code.

## capabilities.items.0.title

Exploration de dépôts et modification de fichiers

## capabilities.items.0.description

Kimi parcourt le dépôt, inspecte les fichiers pertinents et applique des modifications selon le contexte découvert.

## capabilities.items.1.title

Commandes et outils MCP

## capabilities.items.1.description

Il peut exécuter des commandes locales et se connecter à des outils MCP, au-delà de simples suggestions de code.

## capabilities.items.2.title

Flux partagés avec l’extension VS Code

## capabilities.items.2.description

La CLI et l’extension Kimi Code pour VS Code assurent une continuité entre le terminal et l’éditeur.

## faq.items.0.question

Qu’est-ce que Kimi Code CLI ?

## faq.items.0.answer

L’outil s’adresse aux développeurs qui veulent qu’un Agent agisse sur un dépôt local depuis le terminal tout en conservant un passage vers VS Code. Moonshot AI fournit la CLI et l’extension d’éditeur associée.

## faq.items.1.question

Quelles sont les principales capacités de Kimi Code CLI ?

## faq.items.1.answer

Le flux réunit les modifications tenant compte du dépôt, les commandes locales et les outils MCP, puis permet de choisir entre terminal et éditeur selon la tâche.

## faq.items.2.question

Comment installer et lancer Kimi Code CLI ?

## faq.items.2.answer

Choisissez sur cette page la méthode adaptée à votre système, suivez la procédure officielle et démarrez la session depuis le dépôt que Kimi doit examiner.

## faq.items.3.question

Quelles plateformes Kimi Code CLI prend-il en charge ?

## faq.items.3.answer

Il prend en charge macOS, Windows et Linux.
