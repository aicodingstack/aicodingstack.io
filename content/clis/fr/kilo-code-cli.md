## answer

Kilo Code CLI est l’assistant terminal de Kilo pour générer du code, analyser des problèmes et coordonner le développement au moyen de demandes en langage naturel.

## introduction

Décrivez le changement attendu en langage naturel ; Kilo prépare une implémentation, étudie les problèmes et poursuit la tâche dans le terminal.

## faq.items.0.question

Qu’est-ce que Kilo Code CLI ?

## faq.items.0.answer

Kilo Code CLI est l’interface terminal de Kilo pour la programmation assistée par IA. Elle interprète les demandes naturelles comme des tâches de génération, de débogage et de développement.

## faq.items.1.question

Quelles sont les principales capacités de Kilo Code CLI ?

## faq.items.1.answer

Décrivez le code en langage naturel et Kilo peut produire une première implémentation directement dans le terminal. Kilo peut examiner un problème, proposer une correction et aider à valider les changements obtenus. Les commandes en langage naturel coordonnent plusieurs étapes et relient génération de code et débogage.
