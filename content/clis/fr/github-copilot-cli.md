## answer

GitHub Copilot CLI est un agent d’IA en terminal qui répond aux questions, écrit et débogue du code, modifie des projets et utilise GitHub pour créer des pull requests.

## introduction

Il peut servir de partenaire de programmation interactif ou être exécuté de façon programmatique dans des scripts et des automatisations. Depuis un dépôt, il peut analyser le code, implémenter et déboguer des changements, utiliser le contexte GitHub et préparer ou créer des pull requests.

## capabilities.items.0.title

Répondre avec le contexte du projet

## capabilities.items.0.description

Interrogez-le sur la structure du dépôt, un détail d’implémentation ou une erreur inconnue afin d’obtenir une réponse fondée sur le projet actuel.

## capabilities.items.1.title

Écrire, déboguer et modifier le code

## capabilities.items.1.description

Demandez à l’agent d’implémenter des fonctions, de diagnostiquer des échecs et de modifier les fichiers du projet depuis le terminal.

## capabilities.items.2.title

Travailler avec GitHub et les pull requests

## capabilities.items.2.description

Utilisez le contexte et les flux GitHub pour examiner l’activité du dépôt et préparer ou créer des pull requests en ligne de commande.

## faq.items.0.question

Qu’est-ce que GitHub Copilot CLI ?

## faq.items.0.answer

C’est l’agent de programmation en terminal de GitHub, conçu pour analyser les bases de code, implémenter des changements, déboguer les problèmes et accomplir les flux GitHub.

## faq.items.1.question

Quelles sont les principales capacités de GitHub Copilot CLI ?

## faq.items.1.answer

Il peut répondre aux questions sur le code, écrire et déboguer du code, modifier le projet, travailler avec GitHub et créer des pull requests.

## faq.items.2.answer
