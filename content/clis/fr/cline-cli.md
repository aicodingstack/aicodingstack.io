## answer

Cline CLI est un agent de programmation headless pour exécuter des tâches Cline depuis le terminal. Ce produit est proposé par Cline Bot.

## introduction

Cline CLI permet depuis le terminal d’exécuter des tâches d’IA collaboratives sans éditeur interactif, automatiser l’exécution headless, notamment dans GitHub Actions et relier Cline à des bots Discord et des tickets Linear.

## faq.items.0.question

Qu’est-ce que Cline CLI ?

## faq.items.0.answer

Cline CLI est un agent de programmation en terminal proposé par Cline Bot. Il est conçu pour exécuter des tâches d’IA collaboratives sans éditeur interactif.

## faq.items.1.question

Comment installer Cline CLI ?

## faq.items.1.answer

Utilisez la commande d’installation propre à votre plateforme affichée sur cette page ou suivez la documentation officielle. Après l’installation, lancez Cline CLI avec cline.

## faq.items.2.question

Quels systèmes d’exploitation Cline CLI prend-il en charge ?

## faq.items.2.answer

Cline CLI est disponible pour macOS, Windows et Linux, avec la commande cline sur chaque plateforme.
