## answer

Cursor CLI est un agent de ligne de commande assisté par IA pour écrire, réviser et modifier du code. Ce produit est proposé par Anysphere.

## introduction

Cursor CLI permet depuis le terminal d’écrire et modifier du code directement, réviser du code avec l’aide de l’IA et utiliser des modèles avancés de plusieurs fournisseurs.

## faq.items.0.question

Qu’est-ce que Cursor CLI ?

## faq.items.0.answer

Cursor CLI est un agent de programmation en terminal proposé par Anysphere. Il est conçu pour écrire et modifier du code directement dans le terminal.

## faq.items.1.question

Comment installer Cursor CLI ?

## faq.items.1.answer

Utilisez la commande d’installation propre à votre plateforme affichée sur cette page ou suivez la documentation officielle. Après l’installation, lancez Cursor CLI avec cursor-agent.

## faq.items.2.question

Quels systèmes d’exploitation Cursor CLI prend-il en charge ?

## faq.items.2.answer

Cursor CLI est disponible pour macOS, Windows et Linux, avec la commande cursor-agent sur chaque plateforme.
