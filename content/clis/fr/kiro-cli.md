## answer

Kiro CLI est un outil de programmation IA en terminal proposé par AWS, centré sur le développement guidé par les spécifications et complété par des hooks d’Agent, la recherche web et l’assistance en langage naturel.

## introduction

Kiro CLI part d’une spécification écrite qui reste la référence du prototype jusqu’au code de production. Les hooks d’Agent peuvent déclencher des actions répétables, tandis que la recherche web apporte un contexte externe lorsqu’il est nécessaire. Après installation, kiro-cli s’exécute dans le dossier du projet sous macOS, Windows ou Linux.

## capabilities.items.0.title

Développement guidé par les spécifications

## capabilities.items.0.description

Les exigences et la conception sont d’abord consignées dans une spécification, qui sert ensuite de référence pour le prototype, les modifications de code et les objectifs de production.

## capabilities.items.1.title

Hooks d’Agent et recherche web

## capabilities.items.1.description

Les hooks d’Agent déclenchent des actions reproductibles, et la recherche web fournit des informations externes utiles à la tâche en cours.

## capabilities.items.2.title

Assistance au codage en langage naturel

## capabilities.items.2.description

Une tâche de programmation peut être décrite en langage naturel, puis poursuivie dans la même session de terminal pour examiner, modifier et vérifier le projet local.

## faq.items.0.question

Qu’est-ce que Kiro CLI ?

## faq.items.0.answer

L’outil convient aux développeurs qui veulent faire travailler l’Agent à partir d’une spécification explicite plutôt que d’un simple prompt ponctuel. AWS complète cette approche avec l’automatisation du terminal et la recherche externe.

## faq.items.1.question

Que permet de faire Kiro CLI ?

## faq.items.1.answer

Kiro CLI relie une spécification durable à l’implémentation, confie les actions récurrentes aux hooks et ajoute du contexte web lorsque le dépôt ne suffit pas.

## faq.items.2.question

Comment commencer avec Kiro CLI ?

## faq.items.2.answer

Suivez la procédure d’installation officielle correspondant à votre système, puis lancez kiro-cli dans le terminal ouvert sur le dossier du projet.

## faq.items.3.question

Quels systèmes d’exploitation sont pris en charge par Kiro CLI ?

## faq.items.3.answer

Kiro CLI prend en charge macOS, Windows et Linux. Avant l’installation, consultez la documentation officielle pour connaître les exigences propres à chaque système.
