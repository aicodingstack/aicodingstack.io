## faq.items.0.question

Qu’est-ce que Grok Build ?

## faq.items.0.answer

Grok Build est l’agent de codage en terminal open source de xAI pour explorer les dépôts, modifier le code, exécuter des commandes et mener à bien des tâches de développement de bout en bout. Il est conçu pour travailler directement sur un projet depuis une session de terminal.

## faq.items.1.question

Quelles sont les principales capacités de Grok Build ?

## faq.items.1.answer

Grok Build parcourt un dépôt et consulte les fichiers pertinents afin d’ancrer ses changements dans le code actuel. L’agent peut modifier le code et exécuter des commandes, reliant l’implémentation aux vérifications locales. Il peut suivre une tâche de l’exploration à l’édition puis à l’exécution, au lieu de s’arrêter à une suggestion.
