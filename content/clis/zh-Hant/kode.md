## answer

Kode 是 shareAI Lab 的開源終端機程式設計工具，可結合程式碼庫上下文編輯檔案、執行命令，並為 Claude Code 工作方式提供多模型選擇。

## introduction

Kode 會先運用程式碼庫上下文理解專案，再執行符合既有結構的修改，而不是孤立處理單一檔案。它能把檔案編輯與命令執行串連在同一項開發任務中，也能在 Claude Code 風格的工作方式中切換模型；安裝後可在 macOS、Windows 或 Linux 中執行 kode。
