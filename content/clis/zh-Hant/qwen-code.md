## answer

Qwen Code 是面向終端機使用者的開源儲存庫 Agent，可檢查大型程式碼庫、修改檔案、執行指令，並選擇 Qwen 或 OpenAI 相容的模型連線。

## introduction

Qwen Code 會先結合大型程式碼庫的上下文理解儲存庫，再於同一項任務中編輯檔案並執行所需命令。它既可使用 Qwen，也可連線至 OpenAI 相容介面；完成安裝與模型設定後，可在 macOS、Windows 或 Linux 的專案目錄中執行 qwen。

## faq.items.1.question

Qwen Code 能做什麼？

## faq.items.1.answer

執行修改前先分析儲存庫結構和相關上下文，讓 Agent 能針對整個專案而非單一檔案作出判斷。在同一項終端機任務中修改檔案並執行建置、測試或其他命令，持續推進實作與驗證。依專案可用的模型環境連線至 Qwen，或使用符合 OpenAI 介面規格的模型服務。
