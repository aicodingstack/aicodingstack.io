## answer

Cline CLI 是 Cline Bot 推出的用於從終端執行 Cline 任務的無頭程式設計 Agent。

## introduction

透過 Cline CLI，開發者可以在無需互動式編輯器的情況下執行協作式 AI 任務，在 GitHub Actions 等情境中自動進行無頭執行，並將 Cline 工作流程接入 Discord 機器人與 Linear 工單。

## faq.items.0.question

Cline CLI 是什麼？

## faq.items.0.answer

Cline CLI 是 Cline Bot 的終端程式設計 Agent，主要用於無需互動式編輯器即可執行協作式 AI 任務。

## faq.items.1.question

如何安裝 Cline CLI？

## faq.items.1.answer

請使用本頁顯示的對應平台安裝指令，或依照官方安裝文件操作。安裝完成後，執行 cline 啟動 Cline CLI。

## faq.items.2.question

Cline CLI 支援哪些作業系統？

## faq.items.2.answer

Cline CLI 支援 macOS、Windows 與 Linux，並在三個平台上都透過 cline 啟動。

## faq.items.3.question

Cline CLI 如何收費？

## faq.items.3.answer

開源 CLI 本身不收授權費用；AI 推論可能按用量收費，Enterprise 條款採用自訂方式。詳情請查看價格區塊。

## faq.items.4.question

Cline CLI 是開源軟體嗎？

## faq.items.4.answer
