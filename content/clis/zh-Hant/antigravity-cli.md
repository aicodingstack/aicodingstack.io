## answer

Antigravity CLI 是 Google 推出的面向 Antigravity 的終端優先 Agent 協調工具。

## introduction

透過 Antigravity CLI，開發者可以直接在終端中呼叫並監控 Antigravity Agent、協調 subagent、多檔案編輯、工具、MCP 與 skills，以及在本機或透過文件所述的遠端 SSH 支援工作。

## faq.items.0.question

Antigravity CLI 是什麼？

## faq.items.0.answer

Antigravity CLI 是 Google 的終端程式設計 Agent，主要用於從終端呼叫並監控 Antigravity Agent。

## faq.items.1.question

如何安裝 Antigravity CLI？

## faq.items.1.answer

請使用本頁顯示的對應平台安裝指令，或依照官方安裝文件操作。安裝完成後，執行 agy 啟動 Antigravity CLI。

## faq.items.2.question

Antigravity CLI 支援哪些作業系統？

## faq.items.2.answer

Antigravity CLI 支援 macOS、Windows 與 Linux，並在三個平台上都透過 agy 啟動。

## faq.items.3.question

Antigravity CLI 如何收費？

## faq.items.3.answer

Antigravity CLI 提供免費的個人選項、付費 Google AI 方案，以及按用量計費的組織選項。目前條款請查看價格區塊。

## faq.items.4.question

Antigravity CLI 是開源軟體嗎？

## faq.items.4.answer

不是。Antigravity CLI 是專有軟體。
