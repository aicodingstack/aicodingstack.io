## answer

Cursor CLI 是 Anysphere 推出的用於撰寫、審查與修改程式碼的 AI 命令列 Agent。

## introduction

透過 Cursor CLI，開發者可以直接在終端工作階段中撰寫與修改程式碼、運用 AI 審查程式碼，以及使用來自多個供應商的前沿模型。

## faq.items.0.question

Cursor CLI 是什麼？

## faq.items.0.answer

Cursor CLI 是 Anysphere 的終端程式設計 Agent，主要用於直接在終端工作階段中撰寫與修改程式碼。

## faq.items.1.question

如何安裝 Cursor CLI？

## faq.items.1.answer

請使用本頁顯示的對應平台安裝指令，或依照官方安裝文件操作。安裝完成後，執行 cursor-agent 啟動 Cursor CLI。

## faq.items.2.question

Cursor CLI 支援哪些作業系統？

## faq.items.2.answer

Cursor CLI 支援 macOS、Windows 與 Linux，並在三個平台上都透過 cursor-agent 啟動。
