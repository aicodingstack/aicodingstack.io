## answer

GitHub Copilot CLI 是一款終端 AI Agent，可回答問題、撰寫和偵錯程式碼、修改專案，並透過 GitHub 操作建立提取要求。

## introduction

它既可作為互動式程式設計夥伴使用，也可在指令碼和自動化中以程式化方式呼叫。在程式碼儲存庫中，它能調查程式碼、實作並偵錯修改、運用 GitHub 脈絡，以及準備或建立提取要求。

結合專案脈絡回答問題

## capabilities.items.0.description

可以詢問儲存庫結構、實作細節或陌生錯誤，並獲得以目前專案為依據的回答。

撰寫、偵錯和修改程式碼

## capabilities.items.1.description

可讓 Agent 實作功能、診斷失敗並編輯檔案，直接從終端推進專案修改。

## capabilities.items.2.title

操作 GitHub 與提取要求

## capabilities.items.2.description

運用 GitHub 脈絡和工作流程查看儲存庫活動，並從命令列準備或建立提取要求。
