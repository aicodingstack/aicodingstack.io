## answer

Claude Code 是 Anthropic 推出的能理解程式碼庫並執行自然語言任務的終端程式設計助手。

## introduction

透過 Claude Code，開發者可以直接在終端中結合儲存庫脈絡理解並解釋程式碼、執行程式設計任務並管理 Git 工作流程，以及透過 MCP 整合擴充終端工作。

## faq.items.0.question

Claude Code 是什麼？

## faq.items.0.answer

Claude Code 是 Anthropic 的終端程式設計 Agent，主要用於結合儲存庫脈絡理解並解釋程式碼。

## faq.items.1.question

如何安裝 Claude Code？

## faq.items.1.answer

請使用本頁顯示的對應平台安裝指令，或依照官方安裝文件操作。安裝完成後，執行 claude 啟動 Claude Code。

## faq.items.2.question

Claude Code 支援哪些作業系統？

## faq.items.2.answer

Claude Code 支援 macOS、Windows 與 Linux，並在三個平台上都透過 claude 啟動。
