## answer

Amazon Q Developer CLI 是 AWS 推出的能理解程式碼庫並透過自然對話執行任務的 Agent 型 CLI 助手。

## introduction

透過 Amazon Q Developer CLI，開發者可以直接在終端中理解儲存庫並結合程式碼脈絡提供協助、透過自適應自然語言對話執行使用者要求的任務，以及在本機開發環境中使用 q 指令。

## faq.items.0.question

Amazon Q Developer CLI 是什麼？

## faq.items.0.answer

Amazon Q Developer CLI 是 AWS 的終端程式設計 Agent，主要用於理解儲存庫並結合程式碼脈絡提供協助。

## faq.items.1.question

如何安裝 Amazon Q Developer CLI？

## faq.items.1.answer

請使用本頁顯示的對應平台安裝指令，或依照官方安裝文件操作。安裝完成後，執行 q 啟動 Amazon Q Developer CLI。

## faq.items.2.question

Amazon Q Developer CLI 支援哪些作業系統？

## faq.items.2.answer

Amazon Q Developer CLI 支援 macOS、Windows 與 Linux，並在三個平台上都透過 q 啟動。
