## answer

Kimi Code CLI 是 Moonshot AI 的終端機程式設計代理，支援程式碼儲存庫探索、檔案編輯、命令執行、MCP 工具，以及與其 VS Code 擴充功能共享工作流程。

## introduction

開發者可從本機儲存庫開始，讓 Kimi 找出相關程式碼、完成修改並呼叫任務所需的工具，而不只取得對話式建議。需要編輯器檢視時，也能在 Kimi Code 的 VS Code 擴充功能中延續同一項工作。

## capabilities.items.0.title

程式碼儲存庫探索和檔案編輯

## capabilities.items.0.description

Kimi 會瀏覽儲存庫、檢查相關檔案，並結合程式碼庫脈絡套用修改。

## capabilities.items.1.title

指令和 MCP 工具

## capabilities.items.1.description

它能執行本機指令並連接 MCP 工具，不侷限於提供程式碼建議。

## capabilities.items.2.title

與 VS Code 擴充功能共用的工作流程

## capabilities.items.2.description

CLI 與 VS Code 的 Kimi Code 擴充套件支援在終端機和編輯器之間延續同一工作流程。

## faq.items.0.question

Kimi Code CLI 是什麼？

## faq.items.0.answer

它適合希望由 Agent 在終端機中直接處理本機儲存庫，同時又需要切換至 VS Code 的開發者。Moonshot AI 同時提供 CLI 與配套編輯器擴充功能。

## faq.items.1.question

Kimi Code CLI 的核心功能是什麼？

## faq.items.1.answer

其工作方式將程式碼庫感知修改、本機指令和 MCP 工具連接起來，並讓開發者依任務在終端機與編輯器之間切換。

## faq.items.2.question

如何安裝並啟動 Kimi Code CLI？

## faq.items.2.answer

選擇頁面為目前作業系統提供的方式，依官方說明完成設定，再從需要 Kimi 檢查的儲存庫開始工作階段。

## faq.items.3.question

Kimi Code CLI 支援哪些平台？

## faq.items.3.answer

支援 macOS、Windows 和 Linux。 可在這些系統的本機終端機工作流程中使用。

## faq.items.4.question

在哪裡查看 Kimi Code CLI 的價格？

## faq.items.4.answer

Kimi Code CLI 是開源軟體；託管模型的可用性、使用條件與可能產生的費用以 Moonshot AI 官方服務資訊為準。
