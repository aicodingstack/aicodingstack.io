## answer

Kiro CLI 是 AWS 的終端機 AI 程式設計工具，以規範驅動開發為核心，並提供 Agent hook、網路搜尋及自然語言程式設計協助。

## introduction

Kiro CLI 讓開發者從書面規範開始，並在實作過程中持續以規範約束原型與正式程式碼。它也能透過 Agent hook 自動執行重複動作，並在需要外部資訊時使用網路搜尋；完成安裝後，可在 macOS、Windows 或 Linux 的專案目錄中執行 kiro-cli。
