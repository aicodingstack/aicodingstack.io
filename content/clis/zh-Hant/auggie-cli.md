## answer

Auggie CLI 是 Augment 推出的由 Augment 上下文引擎驅動的自主終端 Agent。

## introduction

透過 Auggie CLI，開發者可以直接在終端中運用上下文引擎提供理解程式碼庫的協助、透過原生終端介面執行自主任務，以及將互動式 TUI 與自動化工作流程結合。

## faq.items.0.question

Auggie CLI 是什麼？

## faq.items.0.answer

Auggie CLI 是 Augment 的終端程式設計 Agent，主要用於運用上下文引擎提供理解程式碼庫的協助。

## faq.items.1.question

如何安裝 Auggie CLI？

## faq.items.1.answer

請使用本頁顯示的對應平台安裝指令，或依照官方安裝文件操作。安裝完成後，執行 auggie 啟動 Auggie CLI。

## faq.items.2.question

Auggie CLI 支援哪些作業系統？

## faq.items.2.answer

Auggie CLI 支援 macOS、Windows 與 Linux，並在三個平台上都透過 auggie 啟動。
