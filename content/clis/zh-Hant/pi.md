## answer

Pi 更像一個可程式化的程式設計框架，而不是固定的聊天介面。開發者可以依工作選擇互動模式，並用 TypeScript 元件擴充終端機體驗。

## introduction

Pi 不只提供互動式終端機體驗，也能用列印或 JSON 輸出、RPC 服務與 SDK 等方式嵌入不同工作情境。開發者可用 TypeScript 擴充功能、Skill、主題和套件調整這套程式設計框架；安裝後可在 macOS、Windows 或 Linux 中執行 pi。

## faq.items.1.question

## faq.items.1.answer

依任務選擇互動式操作、適合指令碼處理的列印或 JSON 輸出、RPC 呼叫，或直接透過 SDK 整合。透過 TypeScript 擴充功能和可重複使用的套件增加行為，並用 Skill 與主題調整能力和介面體驗。將 Pi 作為可檢視、可擴充的開源基礎，用於建構終端機中的 Agent 程式設計工作方式。
