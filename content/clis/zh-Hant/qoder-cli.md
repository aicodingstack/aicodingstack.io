## answer

Qoder CLI 是 Alibaba 的專有終端機助理，把程式碼產生、偵錯、TUI、行內對話和以專案為中心的工作整合到同一個開發介面。

## introduction

Qoder CLI 可在終端機中產生程式碼、協助找出問題，並透過 TUI 或行內對話與開發任務互動。它的專案管理能力可與程式碼產生和偵錯連續配合；安裝後可在 macOS、Windows 或 Linux 的專案目錄中執行 qodercli。
