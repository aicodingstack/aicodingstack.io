## answer

Amazon Q Developer CLI es un asistente CLI agéntico que entiende el código y ejecuta tareas mediante diálogo natural. Es un producto de AWS.

## introduction

Amazon Q Developer CLI permite desde el terminal comprender un repositorio y ayudar con el contexto del código, ejecutar tareas solicitadas mediante diálogo adaptativo y usar el comando q desde el entorno de desarrollo local.

## faq.items.0.question

¿Qué es Amazon Q Developer CLI?

## faq.items.0.answer

Amazon Q Developer CLI es un agente de programación para terminal de AWS. Está diseñado para comprender un repositorio y ayudar con el contexto del código.

## faq.items.1.question

¿Cómo instalo Amazon Q Developer CLI?

## faq.items.1.answer

Usa el comando de instalación específico de tu plataforma que aparece en esta página o sigue la documentación oficial. Después de instalarlo, inicia Amazon Q Developer CLI con q.

## faq.items.2.question

¿Qué sistemas operativos admite Amazon Q Developer CLI?

## faq.items.2.answer

Amazon Q Developer CLI está disponible para macOS, Windows y Linux, y se inicia con q en las tres plataformas.
