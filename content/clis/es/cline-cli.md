## answer

Cline CLI es un agente de programación sin interfaz para ejecutar tareas de Cline desde el terminal. Es un producto de Cline Bot.

## introduction

Cline CLI permite desde el terminal ejecutar tareas colaborativas de IA sin editor interactivo, automatizar ejecuciones sin interfaz, como GitHub Actions y conectar flujos de Cline con bots de Discord y tickets de Linear.

## faq.items.0.question

¿Qué es Cline CLI?

## faq.items.0.answer

Cline CLI es un agente de programación para terminal de Cline Bot. Está diseñado para ejecutar tareas colaborativas de IA sin editor interactivo.

## faq.items.1.question

¿Cómo instalo Cline CLI?

## faq.items.1.answer

Usa el comando de instalación específico de tu plataforma que aparece en esta página o sigue la documentación oficial. Después de instalarlo, inicia Cline CLI con cline.

## faq.items.2.question

¿Qué sistemas operativos admite Cline CLI?

## faq.items.2.answer

Cline CLI está disponible para macOS, Windows y Linux, y se inicia con cline en las tres plataformas.
