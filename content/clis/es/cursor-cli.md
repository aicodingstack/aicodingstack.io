## answer

Cursor CLI es un agente de línea de comandos con IA para escribir, revisar y modificar código. Es un producto de Anysphere.

## introduction

Cursor CLI permite desde el terminal escribir y modificar código directamente, revisar código con asistencia de IA y trabajar con modelos avanzados de varios proveedores.

## faq.items.0.question

¿Qué es Cursor CLI?

## faq.items.0.answer

Cursor CLI es un agente de programación para terminal de Anysphere. Está diseñado para escribir y modificar código directamente desde el terminal.

## faq.items.1.question

¿Cómo instalo Cursor CLI?

## faq.items.1.answer

Usa el comando de instalación específico de tu plataforma que aparece en esta página o sigue la documentación oficial. Después de instalarlo, inicia Cursor CLI con cursor-agent.

## faq.items.2.question

¿Qué sistemas operativos admite Cursor CLI?

## faq.items.2.answer

Cursor CLI está disponible para macOS, Windows y Linux, y se inicia con cursor-agent en las tres plataformas.
