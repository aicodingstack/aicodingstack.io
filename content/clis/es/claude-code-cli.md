## answer

Claude Code es un asistente de terminal que entiende el código y ejecuta tareas en lenguaje natural. Es un producto de Anthropic.

## introduction

Claude Code permite desde el terminal comprender y explicar código con contexto del repositorio, ejecutar tareas de programación y gestionar flujos de Git y ampliar el trabajo del terminal mediante integraciones MCP.

## faq.items.0.question

¿Qué es Claude Code?

## faq.items.0.answer

Claude Code es un agente de programación para terminal de Anthropic. Está diseñado para comprender y explicar código con contexto del repositorio.

## faq.items.1.question

¿Cómo instalo Claude Code?

## faq.items.1.answer

Usa el comando de instalación específico de tu plataforma que aparece en esta página o sigue la documentación oficial. Después de instalarlo, inicia Claude Code con claude.

## faq.items.2.question

¿Qué sistemas operativos admite Claude Code?

## faq.items.2.answer

Claude Code está disponible para macOS, Windows y Linux, y se inicia con claude en las tres plataformas.
