## answer

Qoder CLI es el asistente propietario de Alibaba que reúne generación de código, depuración, TUI, chat integrado y trabajo orientado a proyectos en una sola interfaz de terminal.

## introduction

Qoder CLI genera código en el terminal, ayuda a diagnosticar problemas y permite interactuar con la tarea mediante una TUI o un chat integrado. La gestión del proyecto se combina directamente con la generación y la depuración. Tras la instalación, qodercli se ejecuta en el directorio del proyecto en macOS, Windows o Linux.
