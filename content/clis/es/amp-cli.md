## answer

Amp es un agente de programación avanzado para razonamiento autónomo, edición de código y tareas complejas. Es un producto de Sourcegraph.

## introduction

Amp permite desde el terminal razonar de forma autónoma sobre el código y el resultado pedido, editar código y resolver tareas de desarrollo complejas y usar el mismo agente en la CLI y editores compatibles.

## faq.items.0.question

¿Qué es Amp?

## faq.items.0.answer

Amp es un agente de programación para terminal de Sourcegraph. Está diseñado para razonar de forma autónoma sobre el código y el resultado pedido.

## faq.items.1.question

¿Cómo instalo Amp?

## faq.items.1.answer

Usa el comando de instalación específico de tu plataforma que aparece en esta página o sigue la documentación oficial. Después de instalarlo, inicia Amp con amp.

## faq.items.2.question

¿Qué sistemas operativos admite Amp?

## faq.items.2.answer

Amp está disponible para macOS, Windows y Linux, y se inicia con amp en las tres plataformas.
