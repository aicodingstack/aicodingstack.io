## answer

Kiro CLI es una herramienta de programación con IA para terminal de AWS, centrada en el desarrollo guiado por especificaciones y equipada con hooks de agente, búsqueda web y asistencia en lenguaje natural.

## introduction

Kiro CLI parte de una especificación escrita que sigue siendo la referencia desde el prototipo hasta el código de producción. Los hooks de agente pueden activar acciones repetibles y la búsqueda web aporta contexto externo cuando hace falta. Después de instalarlo, kiro-cli se ejecuta desde el directorio del proyecto en macOS, Windows o Linux.

## faq.items.0.question

¿Qué es Kiro CLI?

## faq.items.0.answer

Está pensado para desarrolladores que quieren que el agente trabaje a partir de una especificación explícita, en lugar de depender solo de un prompt improvisado. AWS añade automatización del terminal e investigación externa.

## faq.items.1.question

¿Qué se puede hacer con Kiro CLI?

## faq.items.1.answer

Kiro CLI vincula una especificación duradera con la implementación, asigna las acciones repetitivas a los hooks y añade contexto web cuando el repositorio no basta.

## faq.items.2.question

¿Cómo se empieza a usar Kiro CLI?

## faq.items.2.answer

Sigue las instrucciones oficiales de instalación para tu sistema y, después, ejecuta kiro-cli en el terminal abierto en el directorio del proyecto.
