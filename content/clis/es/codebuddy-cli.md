## answer

CodeBuddy CLI es un editor de terminal con IA para generar código, depurar y organizar el desarrollo. Es un producto de Tencent.

## introduction

CodeBuddy CLI permite desde el terminal generar y modificar código, depurar código con flujos asistidos por IA y trabajar mediante una TUI nativa o chat en línea.

## faq.items.1.answer

Usa el comando de instalación específico de tu plataforma que aparece en esta página o sigue la documentación oficial. Después de instalarlo, inicia CodeBuddy CLI con codebuddy.
