## answer

Pi se entiende mejor como un entorno programable que como una interfaz de chat fija. Permite elegir el modo de interacción y ampliar la experiencia del terminal con componentes TypeScript.

## introduction

Pi no se limita a una sesión interactiva: puede producir texto o JSON, funcionar como servicio RPC o integrarse mediante su SDK. Las extensiones TypeScript, los skills, los temas y los paquetes permiten adaptar el comportamiento y la presentación del entorno. Tras la instalación, pi funciona en macOS, Windows o Linux.

## faq.items.0.question

¿Qué es Pi?

## faq.items.0.answer

Pi es un entorno de programación para terminal de código abierto de Earendil Inc., con modos interactivo, de salida de texto o JSON, RPC y SDK, además de extensiones TypeScript, skills, temas y paquetes.

## faq.items.1.question

¿Qué se puede hacer con Pi?

## faq.items.1.answer

Según la tarea, Pi puede usarse de forma interactiva, con salida de texto o JSON para scripts, mediante llamadas RPC o con una integración directa del SDK. Las extensiones TypeScript y los paquetes reutilizables añaden comportamientos, mientras que los skills y los temas ajustan las capacidades y la interfaz. Pi sirve como base abierta, revisable y ampliable para crear formas de programación asistida por agentes dentro del terminal.
