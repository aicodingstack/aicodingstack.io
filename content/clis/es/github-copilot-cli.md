## answer

GitHub Copilot CLI es un agente de IA para terminal que responde preguntas, escribe y depura código, modifica proyectos y trabaja con GitHub para crear pull requests.

## introduction

Puede funcionar como compañero interactivo de programación o ejecutarse de forma programática en scripts y automatizaciones. Desde un repositorio puede investigar código, implementar y depurar cambios, usar el contexto de GitHub y preparar o crear pull requests.

## capabilities.items.0.title

Responder preguntas con contexto

## capabilities.items.0.description

Pregunta por la estructura del repositorio, detalles de implementación o errores desconocidos y recibe respuestas basadas en el proyecto actual.

## capabilities.items.1.title

Escribir, depurar y modificar código

## capabilities.items.1.description

Pide al agente que implemente funciones, diagnostique fallos y edite archivos mientras trabaja con el proyecto desde el terminal.

## capabilities.items.2.title

Trabajar con GitHub y pull requests

## capabilities.items.2.description

Usa el contexto y los flujos de GitHub para revisar la actividad del repositorio y preparar o crear pull requests desde la línea de comandos.
