## answer

Kimi Code CLI es el agente de terminal de Moonshot AI para explorar repositorios, editar archivos, ejecutar comandos, usar herramientas MCP y compartir flujos con su extensión de VS Code.

## introduction

Un desarrollador puede empezar en un repositorio local y dejar que Kimi revise el código relevante, aplique cambios y utilice las herramientas necesarias, sin reducir la sesión a consejos de chat. Cuando conviene una vista de editor, el mismo trabajo puede continuar en la extensión Kimi Code para VS Code.

## capabilities.items.0.title

Exploración de repositorios y edición de archivos

## capabilities.items.0.description

Kimi navega por el repositorio, inspecciona los archivos relevantes y aplica cambios con el contexto encontrado.

## capabilities.items.1.title

Comandos y herramientas MCP

## capabilities.items.1.description

Puede ejecutar comandos locales y conectarse a herramientas MCP, ampliando la sesión más allá de sugerencias de código.

## capabilities.items.2.title

Flujos compartidos con la extensión de VS Code

## capabilities.items.2.description

La CLI y la extensión Kimi Code para VS Code permiten continuar el trabajo al pasar del terminal al editor.

## faq.items.0.question

¿Qué es Kimi Code CLI?

## faq.items.0.answer

Está pensado para desarrolladores que quieren que un agente actúe sobre un repositorio local desde el terminal y conservar la opción de pasar a VS Code. Moonshot AI ofrece tanto la CLI como la extensión relacionada.

## faq.items.1.question

¿Cuáles son las capacidades principales de Kimi Code CLI?

## faq.items.1.answer

El flujo conecta cambios basados en el repositorio con comandos locales y herramientas MCP, y permite elegir entre terminal y editor según la tarea.

## faq.items.2.question

¿Cómo instalo e inicio Kimi Code CLI?

## faq.items.2.answer

Elige en esta página el método correspondiente a tu sistema, sigue la guía oficial y comienza la sesión desde el repositorio que Kimi debe revisar.

## faq.items.3.question

¿Qué plataformas admite Kimi Code CLI?

## faq.items.3.answer

Admite macOS, Windows y Linux. Se utilizan en flujos de terminal locales.

## faq.items.4.question

¿Dónde puedo consultar los precios de Kimi Code CLI?

## faq.items.4.answer

Kimi Code CLI es de código abierto. Las condiciones, la disponibilidad y los posibles costes de los modelos alojados figuran en la información oficial de Moonshot AI.
