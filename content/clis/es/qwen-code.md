## answer

Qwen Code es un agente de repositorios de código abierto para quienes necesitan estudiar una base de código grande, modificar archivos, ejecutar comandos y elegir conexiones Qwen o compatibles con OpenAI.

## introduction

Qwen Code usa el contexto de un repositorio grande antes de modificar archivos y ejecutar los comandos necesarios dentro de la misma tarea. Puede utilizar Qwen o servicios con una interfaz compatible con OpenAI. Después de instalarlo y configurar el modelo, qwen se ejecuta en el proyecto bajo macOS, Windows o Linux.

## faq.items.0.question

¿Qué es Qwen Code?

## faq.items.0.answer

Qwen Code es un agente de programación para terminal de código abierto de Alibaba, diseñado para comprender repositorios grandes, editar archivos y ejecutar comandos, con conexión a modelos Qwen o compatibles con OpenAI.

## faq.items.1.question

¿Qué se puede hacer con Qwen Code?

## faq.items.1.answer

La estructura del repositorio y el contexto relacionado se analizan antes de cambiar nada para razonar sobre todo el proyecto y no solo sobre un archivo. Los archivos se modifican dentro de la misma tarea de terminal y la compilación, las pruebas u otros comandos continúan la implementación y la verificación. Según el entorno disponible para el proyecto, el agente se conecta a Qwen o a un servicio de modelos con una interfaz compatible con OpenAI.

## faq.items.2.question

## faq.items.2.answer

Instala Qwen Code y configura el acceso al modelo según la documentación oficial; después, ejecuta qwen en el directorio del proyecto local.
