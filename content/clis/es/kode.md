## answer

Kode es una herramienta de programación para terminal de código abierto de shareAI Lab que edita con el contexto del repositorio, ejecuta comandos y permite elegir varios modelos en una experiencia similar a Claude Code.

## introduction

Kode comprende el proyecto a partir del contexto de todo el código y crea cambios acordes con la estructura existente, en lugar de tratar cada archivo por separado. La edición y la ejecución de comandos forman una misma tarea, y la experiencia similar a Claude Code permite cambiar de modelo. Tras la instalación, kode funciona en macOS, Windows o Linux.
