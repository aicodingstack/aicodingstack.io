## answer

Auggie CLI es un agente autónomo de terminal basado en el motor de contexto de Augment. Es un producto de Augment.

## introduction

Auggie CLI permite desde el terminal usar el motor de contexto para asistencia consciente del código, ejecutar trabajo autónomo en una interfaz nativa de terminal y combinar la TUI interactiva con flujos automatizados.

## faq.items.0.question

¿Qué es Auggie CLI?

## faq.items.0.answer

Auggie CLI es un agente de programación para terminal de Augment. Está diseñado para usar el motor de contexto para asistencia consciente del código.

## faq.items.1.question

¿Cómo instalo Auggie CLI?

## faq.items.1.answer

Usa el comando de instalación específico de tu plataforma que aparece en esta página o sigue la documentación oficial. Después de instalarlo, inicia Auggie CLI con auggie.

## faq.items.2.question

¿Qué sistemas operativos admite Auggie CLI?

## faq.items.2.answer

Auggie CLI está disponible para macOS, Windows y Linux, y se inicia con auggie en las tres plataformas.
