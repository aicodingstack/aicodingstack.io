## answer

Qoder CLI는 코드 생성, 디버깅, TUI, 인라인 채팅, 프로젝트 중심 작업을 하나의 터미널 화면에 모은 Alibaba의 독점 개발 도우미입니다.

## introduction

Qoder CLI는 터미널에서 코드를 생성하고 문제를 찾도록 도우며 TUI 또는 인라인 채팅으로 개발 작업과 상호작용합니다. 프로젝트 관리 기능은 코드 생성과 디버깅에 이어서 사용할 수 있습니다. 설치 후 macOS, Windows, Linux의 프로젝트 디렉터리에서 qodercli를 실행합니다.
