## answer

Kode는 코드베이스 맥락을 활용한 편집과 명령 실행을 지원하고 Claude Code 방식에서 여러 모델을 선택할 수 있는 shareAI Lab의 오픈 소스 터미널 코딩 도구입니다.

## introduction

Kode는 파일을 따로 떼어 처리하지 않고 코드베이스 전체 맥락으로 프로젝트를 이해해 기존 구조에 맞는 변경을 만듭니다. 파일 편집과 명령 실행을 하나의 개발 작업으로 이어 갈 수 있고 Claude Code 방식에서 모델도 바꿀 수 있습니다. 설치 후 macOS, Windows, Linux에서 kode를 실행합니다.

## capabilities.items.0.title

코드베이스 맥락을 활용한 편집

## capabilities.items.0.description

프로젝트 전체 맥락으로 변경 위치와 영향을 판단해 기존 코드 구조에 어울리는 수정 사항을 만듭니다.

## capabilities.items.1.title

명령과 개발 워크플로

## capabilities.items.1.description

파일을 바꾼 뒤 빌드, 테스트, 그 밖의 명령을 계속 실행해 필요한 개발 단계를 하나의 작업으로 완료합니다.

## capabilities.items.2.title

## capabilities.items.2.description

Claude Code 방식의 상호작용을 유지하면서 프로젝트 연결 환경과 작업에 맞는 다른 모델을 선택합니다.
