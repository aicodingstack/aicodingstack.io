## introduction

Qwen Code는 대규모 코드베이스의 맥락으로 저장소를 이해한 뒤 같은 작업에서 파일을 편집하고 필요한 명령을 실행합니다. Qwen뿐 아니라 OpenAI 호환 API를 제공하는 모델도 사용할 수 있습니다. 설치와 모델 설정 후 macOS, Windows, Linux의 프로젝트에서 qwen을 실행합니다.
