## answer

Amazon Q Developer CLI는 AWS의 코드베이스를 이해하고 자연어 대화로 작업을 실행하는 에이전트형 CLI 도우미입니다.

## introduction

Amazon Q Developer CLI는 터미널에서 저장소를 이해하고 코드 맥락에 맞게 지원하기, 적응형 자연어 대화로 요청된 작업 실행하기, 로컬 개발 환경에서 q 명령 사용하기를 지원합니다.

## faq.items.0.question

Amazon Q Developer CLI는 무엇인가요?

## faq.items.0.answer

Amazon Q Developer CLI는 AWS의 터미널용 코딩 에이전트입니다. 저장소를 이해하고 코드 맥락에 맞게 지원하기 위해 설계되었습니다.

## faq.items.1.question

Amazon Q Developer CLI를 어떻게 설치하나요?

## faq.items.1.answer

이 페이지에 표시된 플랫폼별 설치 명령을 사용하거나 공식 설치 문서를 따르세요. 설치 후 Amazon Q Developer CLI를 q로 실행합니다.

## faq.items.2.question

Amazon Q Developer CLI는 어떤 운영 체제를 지원하나요?

## faq.items.2.answer

Amazon Q Developer CLI는 macOS, Windows, Linux에서 사용할 수 있으며 각 플랫폼에서 q로 실행합니다.

## faq.items.3.question
