Cursor CLI는 터미널 세션에서 직접 코드 작성하고 수정하기, AI 지원으로 코드 검토하기, 여러 제공업체의 고급 모델 사용하기를 지원합니다.

## faq.items.0.question

Cursor CLI는 무엇인가요?

## faq.items.0.answer

Cursor CLI는 Anysphere의 터미널용 코딩 에이전트입니다. 터미널 세션에서 직접 코드 작성하고 수정하기 위해 설계되었습니다.

## faq.items.1.question

Cursor CLI를 어떻게 설치하나요?

## faq.items.1.answer

이 페이지에 표시된 플랫폼별 설치 명령을 사용하거나 공식 설치 문서를 따르세요. 설치 후 Cursor CLI를 cursor-agent로 실행합니다.

## faq.items.2.question

Cursor CLI는 어떤 운영 체제를 지원하나요?

## faq.items.2.answer

Cursor CLI는 macOS, Windows, Linux에서 사용할 수 있으며 각 플랫폼에서 cursor-agent로 실행합니다.

## faq.items.3.question

Cursor CLI의 가격은 얼마인가요?

## faq.items.3.answer

Cursor CLI에는 무료 옵션과 유료 개인, 팀, Enterprise 플랜이 있습니다. 현재 조건은 가격 섹션에서 확인하세요.

## faq.items.4.question

Cursor CLI는 오픈 소스인가요?

## faq.items.4.answer

아니요. Cursor CLI는 독점 소프트웨어입니다.
