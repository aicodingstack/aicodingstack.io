## answer

Cline CLI는 Cline Bot의 터미널에서 Cline 작업을 실행하는 헤드리스 코딩 에이전트입니다.

## introduction

Cline CLI는 터미널에서 대화형 편집기 없이 협업 AI 작업 실행하기, GitHub Actions 같은 환경에서 헤드리스 실행 자동화하기, Cline 워크플로를 Discord 봇과 Linear 티켓에 연결하기를 지원합니다.
