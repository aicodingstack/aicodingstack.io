## answer

Kimi Code CLI는 저장소 탐색, 파일 편집, 명령 실행, MCP 도구 사용, VS Code 확장과의 공유 워크플로를 위한 Moonshot AI의 터미널 코딩 에이전트입니다.

## introduction

개발자는 로컬 저장소에서 시작해 Kimi가 관련 코드를 찾고 수정하며 필요한 도구까지 실행하도록 할 수 있으므로 대화형 제안만 받고 끝나지 않습니다. 편집기 화면이 더 적합할 때는 Kimi Code의 VS Code 확장에서 같은 작업을 이어 갈 수 있습니다.

## capabilities.items.0.title

저장소 탐색 및 파일 편집

## capabilities.items.0.description

Kimi는 저장소를 탐색하고 관련 파일을 확인한 뒤 코드베이스 맥락에 맞춰 수정합니다.

## capabilities.items.1.title

명령 및 MCP 도구

## capabilities.items.1.description

로컬 명령을 실행하고 MCP 도구에 연결해 단순한 코드 제안을 넘어선 작업을 수행합니다.

## capabilities.items.2.title

VS Code 확장과의 공유 워크플로

## capabilities.items.2.description

CLI와 VS Code용 Kimi Code 확장이 터미널과 편집기 사이의 연속된 워크플로를 지원합니다.

## faq.items.0.question

Kimi Code CLI란 무엇인가요?

## faq.items.0.answer

터미널에서 로컬 저장소를 직접 다루는 에이전트가 필요하면서 상황에 따라 VS Code로 옮기려는 개발자에게 적합합니다. Moonshot AI가 CLI와 연계된 편집기 확장을 함께 제공합니다.

## faq.items.1.question

Kimi Code CLI의 주요 기능은 무엇인가요?

## faq.items.1.answer

저장소 맥락을 반영한 변경, 로컬 명령, MCP 도구를 하나의 작업으로 연결하고 필요에 따라 터미널과 편집기를 오갈 수 있습니다.

## faq.items.2.question

Kimi Code CLI은 어떻게 설치하고 시작하나요?

## faq.items.2.answer

이 페이지에서 운영체제에 맞는 방식을 고르고 공식 설정 안내를 따른 뒤 Kimi가 살펴볼 저장소에서 세션을 시작하세요.

## faq.items.3.question

Kimi Code CLI은 어떤 플랫폼을 지원하나요?

## faq.items.3.answer

macOS, Windows, Linux를 지원합니다. 로컬 터미널 워크플로에서 사용할 수 있습니다.

## faq.items.4.question

Kimi Code CLI의 가격은 어디에서 확인할 수 있나요?

## faq.items.4.answer

Kimi Code CLI는 오픈 소스입니다. 호스팅 모델의 제공 조건, 이용 가능 범위, 비용은 Moonshot AI의 공식 서비스 정보를 확인하세요.
