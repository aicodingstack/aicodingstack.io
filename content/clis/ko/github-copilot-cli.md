## answer

GitHub Copilot CLI는 질문에 답하고, 코드를 작성하고 디버깅하며, 프로젝트를 수정하고, GitHub 작업과 풀 리퀘스트 생성을 수행하는 터미널 AI 에이전트입니다.

## introduction

대화형 코딩 파트너로 사용하거나 스크립트와 자동화에서 프로그래밍 방식으로 호출할 수 있습니다. 저장소에서 코드를 조사하고 변경 사항을 구현하고 디버깅하며, GitHub 맥락을 활용해 풀 리퀘스트를 준비하거나 생성할 수 있습니다.

## capabilities.items.0.title

프로젝트 맥락으로 질문에 답변

## capabilities.items.0.description

저장소 구조, 구현 세부 사항, 낯선 오류를 질문하면 현재 프로젝트를 근거로 한 답변을 받을 수 있습니다.

## capabilities.items.1.title

코드 작성, 디버깅, 수정

## capabilities.items.1.description

에이전트에게 기능 구현, 실패 진단, 파일 편집을 맡겨 터미널에서 프로젝트를 직접 변경할 수 있습니다.

## capabilities.items.2.title

GitHub와 풀 리퀘스트 작업

## capabilities.items.2.description

GitHub 맥락과 워크플로를 사용해 저장소 활동을 확인하고 명령줄에서 풀 리퀘스트를 준비하거나 생성할 수 있습니다.

## faq.items.0.question

GitHub Copilot CLI란 무엇인가요?

## faq.items.0.answer

GitHub의 터미널 네이티브 코딩 에이전트로, 코드베이스 조사, 변경 사항 구현, 문제 디버깅, GitHub 워크플로 완료를 지원합니다.

## faq.items.1.question

GitHub Copilot CLI의 주요 기능은 무엇인가요?

## faq.items.1.answer

코드베이스 질문에 답하고, 코드를 작성하고 디버깅하며, 프로젝트 파일을 수정하고, GitHub 작업과 풀 리퀘스트 생성을 수행할 수 있습니다.

## faq.items.2.question

## faq.items.2.answer

예. 터미널에서 대화형 에이전트로 사용하거나 반복 가능한 스크립트, 자동화, 통합에서 프로그래밍 방식으로 호출할 수 있습니다.
