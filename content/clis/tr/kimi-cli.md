## answer

Kimi Code CLI, depo keşfi, dosya düzenleme, komut yürütme, MCP araçları ve VS Code uzantısıyla paylaşılan iş akışları için Moonshot AI'ın terminal kodlama aracısıdır.

## introduction

Geliştirici yerel bir depodan başlayıp Kimi'nin ilgili kodu incelemesini, değişiklik yapmasını ve gerekli araçları kullanmasını sağlayabilir; oturum yalnızca sohbet önerileriyle sınırlı kalmaz. Düzenleyici görünümü daha uygunsa aynı iş VS Code için Kimi Code uzantısında sürdürülür.

## faq.items.0.question

Kimi Code CLI nedir?

## faq.items.0.answer

Terminalden yerel depoda çalışan bir ajan isteyen ve gerektiğinde VS Code'a geçmek isteyen geliştiricilere yöneliktir. Moonshot AI hem CLI'yi hem ilgili düzenleyici uzantısını sağlar.

## faq.items.1.question

Kimi Code CLI ürününün temel yetenekleri nelerdir?

## faq.items.1.answer

İş akışı depo bağlamına dayalı değişiklikleri yerel komutlar ve MCP araçlarıyla birleştirir, göreve göre terminal ile düzenleyici arasında geçiş sağlar.
