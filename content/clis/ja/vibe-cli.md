## answer

Vibe CLI は、設定可能なターミナルワークフローを通じて、リポジトリ作業を調査と計画から編集とコマンド実行まで進める Mistral AI のオープンソース Agent です。

## introduction

Vibe CLI はリポジトリを調べて次の手順を計画してから、具体的なコード変更とコマンド実行に進みます。チームの進め方に合わせて Agent ワークフローも設定できます。インストール後は macOS、Windows、Linux のプロジェクトディレクトリで vibe を実行します。

## faq.items.0.question

Vibe CLI とは何ですか？

## faq.items.0.answer

Vibe CLI は Mistral AI のオープンソースなターミナル向けコーディングツールで、リポジトリの調査と計画、コード編集とコマンド実行、設定可能な Agent ワークフローに対応します。

## faq.items.1.question

Vibe CLI では何ができますか？

## faq.items.1.answer

リポジトリ構造と関連コードを確認して実行計画を作り、プロジェクトを理解する前に変更を始めるリスクを抑えます。同じターミナル Agent のタスクでコードを編集してコマンドを実行し、実装、確認、検証を連続して進めます。チームがリポジトリ作業を進める方法に合わせて Agent の動作を調整し、プロジェクトごとに適切な手順と制約を適用します。
