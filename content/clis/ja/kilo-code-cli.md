## faq.items.0.question

Kilo Code CLI とは何ですか？

## faq.items.0.answer

Kilo Code CLI は AI 支援コーディングのための Kilo 製ターミナル画面です。自然言語の依頼をコード生成、デバッグ、開発タスクとして解釈します。

## faq.items.1.question

Kilo Code CLI の主な機能は何ですか？

## faq.items.1.answer

必要なコードを自然言語で伝えると、Kilo がターミナル内で実装案を生成します。 問題を調べて修正案を示し、変更後の検証まで支援できるため、新規コード生成だけに限定されません。 自然言語コマンドで複数の開発手順を調整し、コード生成とデバッグを同じセッションでつなげます。
