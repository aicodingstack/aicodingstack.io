## answer

Qwen Code は、大規模なコードベースの調査、ファイル変更、コマンド実行、Qwen または OpenAI 互換モデルへの接続を必要とするターミナル利用者向けのオープンソース Agent です。

## introduction

Qwen Code は大規模コードベースの文脈を使ってリポジトリを理解してから、同じタスク内でファイルを編集し、必要なコマンドを実行します。Qwen に加え、OpenAI 互換 API のモデルも利用できます。インストールとモデル設定後は macOS、Windows、Linux のプロジェクトで qwen を実行します。

Qwen Code とは何ですか？

Qwen Code は Alibaba のオープンソースなターミナル向けコーディング Agent で、大規模コードベースの理解、ファイル編集、コマンド実行に対応し、Qwen または OpenAI 互換モデルへ接続できます。

## faq.items.1.question

Qwen Code では何ができますか？

## faq.items.1.answer

変更前にリポジトリ構造と関連する文脈を分析し、単一ファイルではなくプロジェクト全体を基準に判断します。一つのターミナルタスクでファイルを変更し、ビルド、テスト、その他のコマンドを実行して実装と検証を続けます。プロジェクトで利用できる環境に合わせて Qwen に接続するか、OpenAI 互換 API を提供するモデルサービスを使えます。
