## answer

Amazon Q Developer CLIは、AWSが提供するコードベースを理解し自然な対話でタスクを実行するエージェント型CLIアシスタントです。

## introduction

Amazon Q Developer CLIは、リポジトリを理解してコードの文脈に沿って支援する、適応的な自然言語対話で依頼されたタスクを実行する、ローカル開発環境からqコマンドを利用するといった作業をターミナル内で進められます。

## faq.items.0.question

Amazon Q Developer CLIとは何ですか？

## faq.items.0.answer

Amazon Q Developer CLIはAWSのターミナル向けコーディングエージェントです。リポジトリを理解してコードの文脈に沿って支援するように設計されています。

## faq.items.1.question

Amazon Q Developer CLIをインストールするには？

## faq.items.1.answer

このページに表示されるプラットフォーム別のインストールコマンドを使うか、公式インストールドキュメントに従ってください。インストール後はAmazon Q Developer CLIをqで起動します。

## faq.items.2.question

Amazon Q Developer CLIはどのOSに対応していますか？

## faq.items.2.answer

Amazon Q Developer CLIはmacOS、Windows、Linuxで利用でき、各環境でqから起動します。
