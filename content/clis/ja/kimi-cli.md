## answer

Kimi Code CLI は、リポジトリ探索、ファイル編集、コマンド実行、MCP ツール、VS Code 拡張機能との共有ワークフローに対応する Moonshot AI のターミナル向けコーディングエージェントです。

## introduction

ローカルリポジトリから作業を始め、Kimi に関連コードの確認、変更、必要なツールの実行を任せられるため、会話だけの提案で終わりません。エディターでの確認が適している場面では、Kimi Code の VS Code 拡張機能に同じ作業を引き継げます。

## capabilities.items.0.title

リポジトリ探索とファイル編集

## capabilities.items.0.description

Kimi はリポジトリを移動して関連ファイルを確認し、コードベースの文脈に沿って編集を適用します。

## capabilities.items.1.title

コマンドと MCP ツール

## capabilities.items.1.description

ローカルコマンドの実行と MCP ツールへの接続により、単なるコード提案を超えた作業ができます。

## capabilities.items.2.title

VS Code 拡張機能との共有ワークフロー

## capabilities.items.2.description

CLI と VS Code 向け Kimi Code 拡張が、ターミナルとエディターをまたぐ連続した作業を支えます。

## faq.items.0.question

Kimi Code CLI とは何ですか？

## faq.items.0.answer

ターミナルからローカルリポジトリに対して Agent を動かしつつ、必要に応じて VS Code へ移りたい開発者向けです。Moonshot AI が CLI と関連するエディター拡張機能を提供しています。

## faq.items.1.question

Kimi Code CLI の主な機能は何ですか？

## faq.items.1.answer

リポジトリを踏まえた変更、ローカルコマンド、MCP ツールを一つの作業にまとめ、タスクに応じてターミナルとエディターを使い分けられます。

## faq.items.2.question

Kimi Code CLI をインストールして起動するには？

## faq.items.2.answer

このページで OS に合う方法を選び、公式の設定手順に従ったうえで、Kimi に確認させたいリポジトリからセッションを開始します。

## faq.items.3.answer

macOS、Windows、Linux に対応しています。 ローカルのターミナル作業で利用できます。
