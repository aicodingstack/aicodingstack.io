## answer

Kode は shareAI Lab のオープンソースなターミナル向けコーディングツールで、コードベースを踏まえた編集とコマンド実行に加え、Claude Code 型の操作で複数モデルを選べます。

## introduction

Kode はコードベース全体の文脈を使ってプロジェクトを理解し、ファイルを単独で扱うのではなく既存構造に沿った変更を行います。ファイル編集とコマンド実行を一つの開発タスクとして進められ、Claude Code 型の操作でモデルも切り替えられます。インストール後は macOS、Windows、Linux で kode を実行します。
