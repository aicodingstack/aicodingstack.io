## answer

GitHub Copilot CLIは、質問への回答、コードの作成とデバッグ、プロジェクトの変更、GitHub操作やプルリクエスト作成に対応するターミナル向けAIエージェントです。

## introduction

対話型のコーディングパートナーとしても、スクリプトや自動化からプログラム的に呼び出すこともできます。リポジトリ内でコードを調査し、変更を実装・デバッグし、GitHubの文脈を利用してプルリクエストを準備または作成できます。

## capabilities.items.0.title

プロジェクトの文脈で質問に回答

## capabilities.items.0.description

リポジトリ構成、実装の詳細、見慣れないエラーについて質問し、現在のプロジェクトに基づく回答を得られます。

## capabilities.items.1.title

コードを作成、デバッグ、変更

## capabilities.items.1.description

機能の実装、失敗の診断、ファイル編集をエージェントに依頼し、ターミナルからプロジェクトを変更できます。

## capabilities.items.2.title

GitHubとプルリクエストを操作

## capabilities.items.2.description

GitHubの文脈とワークフローを使ってリポジトリの活動を確認し、コマンドラインからプルリクエストを準備または作成できます。

## faq.items.0.question

GitHub Copilot CLI とは何ですか？

## faq.items.0.answer

GitHubが提供するターミナルネイティブのコーディングエージェントで、コードベースの調査、変更の実装、問題のデバッグ、GitHubワークフローの完了に対応します。

## faq.items.1.question

GitHub Copilot CLI の主な機能は何ですか？

## faq.items.1.answer

コードベースへの質問、コードの作成とデバッグ、プロジェクトファイルの変更、GitHub操作、プルリクエスト作成に対応します。

## faq.items.2.question

GitHub Copilot CLIは対話型とプログラム型の両方で使えますか？

## faq.items.2.answer

はい。ターミナルで対話型エージェントとして使うほか、再現可能なスクリプト、自動化、連携からプログラム的に呼び出せます。

## faq.items.3.question

GitHub Copilot CLI はどのプラットフォームに対応していますか？

## faq.items.3.answer

macOS、Windows、Linux に対応しています。 ローカルのターミナル作業で利用できます。
