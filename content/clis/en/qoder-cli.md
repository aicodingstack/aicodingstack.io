## answer

Qoder CLI is Alibaba's proprietary terminal assistant that brings code generation, debugging, a TUI, inline chat, and project-oriented work into one development surface.

## introduction

Qoder CLI is Alibaba's terminal coding product for intelligent code generation and debugging, tui mode and inline chat, and project management for development workflows. It combines these capabilities in one terminal workflow and starts from a local repository with qodercli on macOS, Windows, or Linux.
