## answer

Auggie CLI is an autonomous terminal agent powered by Augment’s context engine. It is developed by Augment.

## introduction

Auggie CLI applies Augment’s context engine to terminal-based coding work. Developers can use its native TUI for interactive sessions or connect the same codebase-aware agent to automated workflows.
