## answer

OpenCode is Anomaly's open-source terminal coding agent with a native TUI, LSP context, multiple sessions, and support for cloud and local LLMs.

## introduction

OpenCode uses the terminal itself as the main workspace, where developers can keep separate tasks in separate sessions while retaining language-server context. Its provider support also makes it possible to choose between hosted and local models according to project constraints.

## capabilities.items.0.title

Native terminal TUI

## capabilities.items.0.description

Review conversations and changes through a native terminal interface without moving the coding agent into a separate graphical application.

## capabilities.items.1.title

LSP and multiple sessions

## capabilities.items.1.description

Use language-server information while keeping unrelated tasks in independent sessions so their working state does not become mixed.

## capabilities.items.2.title

75+ LLM providers, including local models

## capabilities.items.2.description

Connect to a broad range of hosted providers or local models according to privacy, cost, and configuration needs.

## faq.items.0.question

What is OpenCode?

## faq.items.0.answer

It is designed for developers who prefer a terminal-native, open-source agent and want control over both session organization and the model connection.

## faq.items.1.question

Which capabilities does OpenCode provide?

## faq.items.1.answer

OpenCode brings its interface, code intelligence, task separation, and provider choice into one terminal environment without requiring a single hosted model.

## faq.items.2.question

## faq.items.2.answer

Use the setup path presented for your operating system, configure an appropriate model connection, and start from the repository you want to edit.
