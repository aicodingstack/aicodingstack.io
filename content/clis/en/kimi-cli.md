## answer

Kimi Code CLI is Moonshot AI's terminal coding agent for exploring repositories, editing files, running commands, using MCP tools, and continuing work in its VS Code extension.

## introduction

A developer can begin in a local repository, let Kimi inspect the relevant code, apply changes, and run supporting tools without reducing the session to a chat-only exchange. Work can then continue in the Kimi Code extension when an editor view is more useful.

## faq.items.0.question

What is Kimi Code CLI?

## faq.items.0.answer

It is intended for developers who want an agent to act on a local repository from the terminal while retaining a path into VS Code. Moonshot AI provides both the CLI and the related editor extension.
