## faq.items.0.question

What is Junie CLI?

## faq.items.0.answer

Junie CLI is JetBrains' model-agnostic terminal coding agent for planning changes, editing repositories, running development tools, and using reusable agent configurations. It is designed to work directly on a real project from a terminal session.

## faq.items.1.question

What are the core capabilities of Junie CLI?

## faq.items.1.answer

Junie CLI is differentiated by plan-first changes, model-agnostic operation, and reusable agent configuration within the JetBrains ecosystem.
