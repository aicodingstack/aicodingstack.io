## answer

Cline CLI is a headless coding agent for running Cline tasks from the terminal. It is developed by Cline Bot.

## introduction

Cline CLI packages Cline’s collaborative AI workflow for headless execution. It can run outside an interactive editor, which makes it suitable for automation such as GitHub Actions and integrations triggered from Discord bots or Linear tickets.

## faq.items.0.question

What is Cline CLI?

## faq.items.0.answer

Cline CLI is a terminal coding agent from Cline Bot. It is designed to run collaborative AI tasks without an interactive editor.

## faq.items.1.question

How do I install Cline CLI?

## faq.items.1.answer

Install the published Cline CLI package with a supported Node.js package manager, then run cline from the terminal.

## faq.items.2.question

Which operating systems does Cline CLI support?

## faq.items.2.answer

Cline CLI is available for macOS, Windows, and Linux, and starts with cline on each platform.
