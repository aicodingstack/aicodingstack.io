## answer

Claude Code is a terminal coding assistant that understands codebases and executes natural-language tasks. It is developed by Anthropic.

## introduction

Claude Code works directly with a repository from the terminal. It can explain unfamiliar code, carry out coding tasks, manage Git-oriented workflows, and connect external tools or context through MCP.

## capabilities.items.0.title

Understand and explain code

## capabilities.items.0.description

Inspect repository context to answer questions and explain how the relevant code fits together before changes are made.

## capabilities.items.1.title

Run coding and Git tasks

## capabilities.items.1.description

Carry out coding tasks and support Git workflows from the same terminal session used to inspect and verify the work.

## capabilities.items.2.title

Connect tools through MCP

## capabilities.items.2.description

Connect MCP integrations so the coding session can use additional tools and context beyond the local repository.
