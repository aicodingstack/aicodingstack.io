## answer

Droid CLI is Factory AI's terminal coding agent for teams that want feature work carried from planning through testing, with enterprise context and reviewable diffs.

## introduction

A developer gives Droid a feature goal; the agent plans the work, edits the relevant files, runs checks, and exposes the proposed diff before the change is accepted.
