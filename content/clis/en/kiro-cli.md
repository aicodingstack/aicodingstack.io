## answer

Kiro CLI is AWS's terminal coding tool for specification-driven development, agent hooks, web search, and natural-language assistance.

## introduction

Kiro CLI begins with a written specification and keeps it available as work advances from an idea toward production code. Developers can automate repeatable actions with agent hooks and bring external context into a task through web search.

Write the requirements and design first, then use that specification as the reference for implementation decisions and later changes.

## capabilities.items.1.title

Agent hooks and web search

## faq.items.0.question

What is Kiro CLI?

## faq.items.0.answer

It is aimed at developers who want the coding agent to work from an explicit specification instead of relying only on an ad hoc prompt. AWS combines that approach with terminal automation and research tools.

## faq.items.1.question

Which capabilities does Kiro CLI provide?

## faq.items.1.answer

The core workflow links a durable specification to implementation, uses hooks for recurring actions, and adds web context when repository information alone is insufficient.
