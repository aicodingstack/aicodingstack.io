## answer

Cursor CLI is an AI-powered command-line agent for writing, reviewing, and modifying code. It is developed by Anysphere.

## introduction

Cursor CLI brings Cursor’s coding agent to command-line workflows. It can write or modify code, review changes with AI assistance, and use frontier models from more than one provider without requiring the editor interface.
