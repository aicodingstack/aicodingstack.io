## answer

Antigravity CLI is terminal-first agent orchestration for Antigravity. It is developed by Google.

## introduction

Antigravity CLI is the terminal interface for running and supervising Antigravity agents. Its orchestration features cover subagents, multi-file edits, tools, MCP, and skills, while remote SSH support extends the workflow beyond the local machine.

## faq.items.0.question

What is Antigravity CLI?

## faq.items.0.answer

Antigravity CLI is a terminal coding agent from Google. It is designed to invoke and monitor Antigravity agents from the terminal.

## faq.items.1.question

How do I install Antigravity CLI?

## faq.items.1.answer

Follow the official Antigravity installation instructions for your operating system. The agy command then opens the CLI.

## faq.items.2.question

Which operating systems does Antigravity CLI support?

## faq.items.2.answer

Antigravity CLI is available for macOS, Windows, and Linux, and starts with agy on each platform.
