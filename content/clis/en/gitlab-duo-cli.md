## faq.items.0.question

What is GitLab Duo CLI?

## faq.items.0.answer

GitLab Duo CLI is GitLab's terminal coding agent for understanding projects, editing code, running tests, and integrating AI-assisted work with GitLab development workflows. It is designed to work directly on a real project from a terminal session.
