## answer

Amp is a frontier coding agent for autonomous reasoning, code editing, and complex tasks. It is developed by Sourcegraph.

## introduction

Amp is designed for substantial coding tasks rather than isolated completions. It can reason about the requested outcome, edit the codebase autonomously, and carry the same agent experience between its CLI and supported editor integrations.
