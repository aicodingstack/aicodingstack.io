## answer

Pi is best understood as a programmable coding harness rather than a single fixed chat interface. It lets developers choose an interaction mode and extend the terminal experience with TypeScript-based components.

## introduction

Pi is Earendil Inc.'s terminal coding product for interactive, print/json, rpc, and sdk modes, typescript extensions, skills, themes, and packages, and an open-source coding harness. It combines these capabilities in one terminal workflow and starts from a local repository with pi on macOS, Windows, or Linux.
