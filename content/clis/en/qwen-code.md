## answer

Qwen Code is an open-source repository agent for terminal users who need to inspect a large codebase, change files, run commands, and choose between Qwen and OpenAI-compatible model connections.

## introduction

Qwen Code is Alibaba's terminal coding product for large-codebase understanding, file editing and command execution, and qwen and openai-compatible model connections. It combines these capabilities in one terminal workflow and starts from a local repository with qwen on macOS, Windows, or Linux.
