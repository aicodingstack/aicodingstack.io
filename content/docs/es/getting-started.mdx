# Primeros Pasos

AI Coding Stack es un directorio integral y repositorio de metadatos para el ecosistema de programación con IA. Esta guía te ayudará a entender cómo usar el sitio web y contribuir al proyecto.

## Explorando el Stack

### Explorar Categorías

Visita [aicodingstack.io](https://aicodingstack.io) para explorar diferentes categorías de herramientas de programación con IA:

- **IDEs** - Encuentra entornos de desarrollo integrados con IA (VS Code, Cursor, TRAE)
- **CLIs** - Explora asistentes de programación con IA por línea de comandos (Codex, Claude Code)
- **Modelos** - Compara modelos de lenguaje grande para programación (Kimi K2, DeepSeek V3.1, GLM 4.5, Qwen3 Coder)
- **Proveedores** - Revisa proveedores de API de LLM (DeepSeek, Moonshot, SiliconFlow, OpenRouter)

### Comparar Herramientas

Usa el sitio web para comparar diferentes herramientas lado a lado, revisando sus características, capacidades y enlaces a documentación oficial.

## Contribuir a los Metadatos

AI Coding Stack es mantenido por la comunidad. Puedes contribuir agregando nuevas herramientas o actualizando entradas existentes en nuestros archivos de manifiesto.

### Comprender los Manifiestos

Todos los metadatos de herramientas se almacenan en archivos JSON en el directorio `manifests/`:

- `ides.json` - Metadatos de IDEs
- `clis.json` - Metadatos de herramientas CLI
- `models.json` - Metadatos de modelos LLM
- `providers.json` - Metadatos de proveedores de API

### Agregar una Nueva Herramienta

1. Clona el repositorio
2. Ubica el archivo de manifiesto apropiado en `manifests/`
3. Agrega tu entrada siguiendo el esquema existente
4. Asegúrate de que todas las URLs sean accesibles
5. Envía una solicitud de extracción

### Ejemplos de Esquemas de Manifiesto

**Para IDEs/CLIs:**
```json
{
  "name": "Nombre de Herramienta",
  "id": "tool-id",
  "vendor": "Nombre de Proveedor",
  "description": "Descripción breve",
  "websiteUrl": "https://...",
  "docsUrl": "https://...",
  "latestVersion": "1.0.0"
}
```

**Para Modelos:**
```json
{
  "name": "Nombre de Modelo",
  "vendor": "Proveedor",
  "id": "model-id",
  "size": "70B",
  "contextWindow": 128000,
  "maxOutput": 4096,
  "pricing": {...},
  "urls": {...}
}
```
