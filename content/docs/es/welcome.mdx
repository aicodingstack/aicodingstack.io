# Bienvenido

Bienvenido a la documentación de AI Coding Stack. AI Coding Stack es un directorio integral y repositorio de metadatos para el ecosistema de programación con IA.

## ¿Qué es AI Coding Stack?

AI Coding Stack tiene dos propósitos principales:

1. **Un sitio web público** en [aicodingstack.io](https://aicodingstack.io) para descubrir y comparar herramientas de programación con IA
2. **Un repositorio de metadatos mantenido por la comunidad** que contiene información curada sobre herramientas de programación, modelos y plataformas

## Características principales

### Cobertura integral
Explora una amplia gama de herramientas de programación con IA en múltiples categorías:
- **IDEs** - Entornos de desarrollo integrados con integración de IA
- **CLIs** - Asistentes de programación con IA por línea de comandos
- **Modelos** - Modelos de lenguaje grande optimizados para tareas de programación
- **Proveedores** - Proveedores de API de LLM y plataformas

### Impulsado por la comunidad
Todos los metadatos se mantienen en archivos de manifiesto JSON, lo que facilita que la comunidad contribuya, actualice y mejore la información sobre varias herramientas.

### Descubrimiento fácil
Navega, compara y descubre las herramientas de programación con IA adecuadas para tu flujo de trabajo a través de nuestra interfaz web intuitiva.
