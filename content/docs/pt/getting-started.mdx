# Como começar

AI Coding Stack é um diretório abrangente e repositório de metadados para o ecossistema de codificação com IA. Este guia ajudará você a entender como usar o site e contribuir para o projeto.

## Explorando o stack

### Navegar por categorias

Visite [aicodingstack.io](https://aicodingstack.io) para explorar diferentes categorias de ferramentas de codificação com IA:

- **IDEs** - Encontre ambientes de desenvolvimento integrados com IA (VS Code, Cursor, TRAE)
- **CLIs** - Explore assistentes de codificação com IA por linha de comando (Codex, Claude Code)
- **Models** - Compare modelos de linguagem grandes para codificação (Kimi K2, DeepSeek V3.1, GLM 4.5, Qwen3 Coder)
- **Providers** - Revise provedores de API LLM (DeepSeek, Moonshot, SiliconFlow, OpenRouter)

### Comparar ferramentas

Use o site para comparar diferentes ferramentas lado a lado, revisando seus recursos, funcionalidades e links para a documentação oficial.

## Contribuindo com os metadados

AI Coding Stack é mantido pela comunidade. Você pode contribuir adicionando novas ferramentas ou atualizando entradas existentes em nossos arquivos de manifesto.

### Entendendo manifests

Todos os metadados de ferramentas são armazenados em arquivos JSON no diretório `manifests/`:

- `ides.json` - Metadados de IDE
- `clis.json` - Metadados de ferramentas CLI
- `models.json` - Metadados de modelos LLM
- `providers.json` - Metadados de provedores de API

### Adicionando uma nova ferramenta

1. Clone o repositório
2. Localize o arquivo de manifesto apropriado em `manifests/`
3. Adicione sua entrada seguindo o esquema existente
4. Certifique-se de que todas as URLs estejam acessíveis
5. Envie um pull request

### Exemplos de esquema de manifest

**Para IDEs/CLIs:**
```json
{
  "name": "Tool Name",
  "id": "tool-id",
  "vendor": "Vendor Name",
  "description": "Brief description",
  "websiteUrl": "https://...",
  "docsUrl": "https://...",
  "latestVersion": "1.0.0"
}
```

**Para Models:**
```json
{
  "name": "Model Name",
  "vendor": "Vendor",
  "id": "model-id",
  "size": "70B",
  "contextWindow": 128000,
  "maxOutput": 4096,
  "pricing": {...},
  "urls": {...}
}
```
