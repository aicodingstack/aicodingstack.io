# Bem-vindo

Bem-vindo à documentação do AI Coding Stack. AI Coding Stack é um diretório abrangente e repositório de metadados para o ecossistema de codificação com IA.

## O que é AI Coding Stack?

AI Coding Stack tem dois propósitos principais:

1. **Um site público** em [aicodingstack.io](https://aicodingstack.io) para descobrir e comparar ferramentas de codificação com IA
2. **Um repositório de metadados mantido pela comunidade** contendo informações selecionadas sobre ferramentas de codificação, modelos e plataformas

## Recursos principais

### Cobertura abrangente
Explore uma ampla gama de ferramentas de codificação com IA em várias categorias:
- **IDEs** - Ambientes de desenvolvimento integrados com integração de IA
- **CLIs** - Assistentes de codificação com IA por linha de comando
- **Models** - Modelos de linguagem grandes otimizados para tarefas de codificação
- **Providers** - Provedores de API LLM e plataformas

### Orientado pela comunidade
Todos os metadados são mantidos em arquivos de manifesto JSON, facilitando a contribuição, atualização e melhoria das informações sobre várias ferramentas pela comunidade.

### Descoberta fácil
Navegue, compare e descubra as ferramentas de programação com IA certas para seu fluxo de trabalho por meio da nossa interface web intuitiva.
