# Добро пожаловать

Добро пожаловать в документацию AI Coding Stack. AI Coding Stack — это комплексный каталог и репозиторий метаданных для экосистемы ИИ-программирования.

## Что такое AI Coding Stack?

AI Coding Stack выполняет две основные функции:

1. **Общедоступный веб-сайт** на [aicodingstack.io](https://aicodingstack.io) для поиска и сравнения ИИ-инструментов программирования
2. **Поддерживаемый сообществом репозиторий метаданных**, содержащий curated-информацию о средствах программирования, моделях и платформах

## Основные функции

### Комплексное покрытие
Исследуйте широкий спектр ИИ-инструментов программирования в нескольких категориях:
- **IDEs** — Интегрированные среды разработки с Интеграции ИИ
- **CLIs** — Командные ассистенты программирования ИИ
- **Models** — Крупные языковые модели, оптимизированные для задач программирования
- **Providers** — Поставщики LLM API и платформы

### Управляемый сообществом
Все метаданные поддерживаются в файлах JSON-манифестов, что позволяет сообществу легко вносить вклад, обновлять и улучшать информацию о различных инструментах.

### Легкое обнаружение
Просматривайте, сравнивайте и находите подходящие ИИ-инструменты программирования для вашего рабочего процесса через наш интуитивно понятный веб-интерфейс.
