# Начало работы

AI Coding Stack — это комплексный каталог и репозиторий метаданных для экосистемы ИИ-программирования. Это руководство поможет вам понять, как использовать сайт и вносить вклад в проект.

## Изучение стека

### Просмотр категорий

Посетите [aicodingstack.io](https://aicodingstack.io), чтобы изучить различные категории ИИ-инструментов программирования:

- **IDEs** — Найдите интегрированные среды разработки на базе ИИ (VS Code, Cursor, TRAE)
- **CLIs** — Изучите командные ассистенты программирования ИИ (Codex, Claude Code)
- **Models** — Сравните крупные языковые модели для программирования (Kimi K2, DeepSeek V3.1, GLM 4.5, Qwen3 Coder)
- **Providers** — Обзоры поставщиков LLM API (DeepSeek, Moonshot, SiliconFlow, OpenRouter)

### Сравнение инструментов

Используйте сайт для сравнения различных инструментов, просматривая их функции, возможности и ссылки на официальную документацию.

## Вклад в метаданные

AI Coding Stack поддерживается сообществом. Вы можете внести вклад, добавив новые инструменты или обновив существующие записи в наших файлах манифестов.

### Понимание манифестов

Все метаданные инструментов хранятся в файлах JSON в каталоге `manifests/`:

- `ides.json` — Метаданные IDE
- `clis.json` — Метаданные инструментов CLI
- `models.json` — Метаданные моделей LLM
- `providers.json` — Метаданные поставщиков API

### Добавление нового инструмента

1. Клонируйте репозиторий
2. Найдите соответствующий файл манифеста в `manifests/`
3. Добавьте свою запись, следуя существующей схеме
4. Убедитесь, что все URL доступны
5. Отправьте pull request

### Примеры схем манифестов

**Для IDEs/CLIs:**
```json
{
  "name": "Имя инструмента",
  "id": "tool-id",
  "vendor": "Имя поставщика",
  "description": "Краткое описание",
  "websiteUrl": "https://...",
  "docsUrl": "https://...",
  "latestVersion": "1.0.0"
}
```

**Для Models:**
```json
{
  "name": "Имя модели",
  "vendor": "Поставщик",
  "id": "model-id",
  "size": "70B",
  "contextWindow": 128000,
  "maxOutput": 4096,
  "pricing": {...},
  "urls": {...}
}
```
