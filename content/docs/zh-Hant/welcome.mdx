# 歡迎

歡迎來到 AI Coding Stack 文檔。AI Coding Stack 是 AI 編碼生態系統的綜合目錄和元數據存儲庫。

## 什麼是 AI Coding Stack？

AI Coding Stack 具有兩個主要目的：

1. **公開網站** [aicodingstack.io](https://aicodingstack.io)，用於發現和比較 AI 編碼工具
2. **社群維護的元數據存儲庫**，包含關於編碼工具、模型和平台的精選信息

## 主要功能

### 全面覆蓋
探索多個類別中的廣泛 AI 編碼工具：
- **IDEs** - 具有 AI 集成的集成開發環境
- **CLIs** - 命令行 AI 編碼助手
- **Models** - 為編碼任務優化的大型語言模型
- **Providers** - LLM API 提供商和平台

### 社群驅動
所有元數據都維護在 JSON manifest 文件中，讓社群能夠輕鬆貢獻、更新和改進各種工具的信息。

### 易於發現
通過我們直觀的網站介面，瀏覽、比較和發現適合您工作流程的正確 AI 編碼工具。
