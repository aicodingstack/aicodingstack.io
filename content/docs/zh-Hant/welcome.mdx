# 歡迎

歡迎使用 AI Coding Stack 文件。AI Coding Stack 是 AI 程式開發生態系統的完整目錄與詮釋資料儲存庫。

## AI Coding Stack 是什麼？

AI Coding Stack 有兩項主要用途：

1. **公開網站**：透過 [aicodingstack.io](https://aicodingstack.io) 探索並比較 AI 程式開發工具
2. **由社群維護的詮釋資料儲存庫**：收錄程式開發工具、模型與平台的精選資訊

## 主要功能

### 完整涵蓋
探索多種類別的 AI 程式開發工具：
- **IDE** - 整合 AI 的開發環境
- **CLI** - 命令列 AI 程式開發助理
- **模型** - 針對程式開發工作最佳化的大型語言模型
- **供應商** - LLM API 供應商與平台

### 社群協作
所有詮釋資料都保存在 JSON manifest 檔案中，方便社群貢獻、更新與改善各項工具資訊。

### 輕鬆探索
透過直覺的網站介面瀏覽、比較並找出適合工作流程的 AI 程式開發工具。
