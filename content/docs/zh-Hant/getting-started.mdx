# 快速開始

AI Coding Stack 是 AI 編碼生態系統的綜合目錄和元數據存儲庫。本指南將幫助您了解如何使用網站並為項目做出貢獻。

## 探索 Stack

### 瀏覽類別

訪問 [aicodingstack.io](https://aicodingstack.io) 以探索不同類別的 AI 編碼工具：

- **IDEs** - 尋找 AI 驅動的集成開發環境（VS Code、Cursor、TRAE）
- **CLIs** - 探索命令行 AI 編碼助手（Codex、Claude Code）
- **Models** - 比較編碼用大型語言模型（Kimi K2、DeepSeek V3.1、GLM 4.5、Qwen3 Coder）
- **Providers** - 審查 LLM API 提供商（DeepSeek、Moonshot、SiliconFlow、OpenRouter）

### 比較工具

使用並排比較網站上的不同工具，查看它們的功能、能力和官方文檔鏈接。

## 為元數據做出貢獻

AI Coding Stack 由社群維護。您可以通過在我們的 manifest 文件中添加新工具或更新現有條目來做出貢獻。

## 理解 Manifest

所有工具元數據都存儲在 `manifests/` 目錄下的 JSON 文件中：

- `ides.json` - IDE 元數據
- `clis.json` - CLI 工具元數據
- `models.json` - LLM 模型元數據
- `providers.json` - API 提供商元數據

### 添加新工具

1. 複製存儲庫
2. 在 `manifests/` 中找到適當的 manifest 文件
3. 按照現有架構添加您的條目
4. 確保所有 URL 都可訪問
5. 提交 pull request

### Manifest 架構示例

**對於 IDEs/CLIs：**
```json
{
  "name": "工具名稱",
  "id": "tool-id",
  "vendor": "供應商名稱",
  "description": "簡短描述",
  "websiteUrl": "https://...",
  "docsUrl": "https://...",
  "latestVersion": "1.0.0"
}
```

**對於 Models：**
```json
{
  "name": "模型名稱",
  "vendor": "供應商",
  "id": "model-id",
  "size": "70B",
  "contextWindow": 128000,
  "maxOutput": 4096,
  "pricing": {...},
  "urls": {...}
}
```

## 後續步驟

- 瀏覽 [AI Coding Stack](/ai-coding-stack) 以發現工具
- 檢查 `manifests/` 目錄以查看元數據是如何構建的
- 閱讀 [CLAUDE.md](https://github.com/aicodingstack/aicodingstack.io/blob/main/CLAUDE.md) 以獲取詳細的貢獻指南
- 提交您的第一次貢獻以幫助擴展目錄
