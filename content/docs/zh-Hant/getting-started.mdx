# 開始使用

AI Coding Stack 是 AI 程式開發生態系統的完整目錄與詮釋資料儲存庫。本指南將協助你瞭解如何使用網站，以及如何參與專案。

## 探索技術堆疊

### 瀏覽類別

前往 [aicodingstack.io](https://aicodingstack.io)，探索不同類別的 AI 程式開發工具：

- **IDE** - 尋找整合 AI 的開發環境（VS Code、Cursor、TRAE）
- **CLI** - 探索命令列 AI 程式開發助理（Codex、Claude Code）
- **模型** - 比較適合程式開發的大型語言模型（Kimi K2、DeepSeek V3.1、GLM 4.5、Qwen3 Coder）
- **供應商** - 查看 LLM API 供應商（DeepSeek、Moonshot、SiliconFlow、OpenRouter）

### 比較工具

使用網站並排比較不同工具，檢視功能、能力與官方文件連結。

## 貢獻詮釋資料

AI Coding Stack 由社群共同維護。你可以在 manifest 檔案中新增工具，或更新既有項目。

### 認識 Manifest

所有工具的詮釋資料都儲存在 `manifests/` 目錄下的 JSON 檔案：

- `ides.json` - IDE 詮釋資料
- `clis.json` - CLI 工具詮釋資料
- `models.json` - LLM 模型詮釋資料
- `providers.json` - API 供應商詮釋資料

### 新增工具

1. 複製儲存庫
2. 在 `manifests/` 中找到適當的 manifest 檔案
3. 依照現有結構新增項目
4. 確認所有 URL 均可存取
5. 提交 pull request

### Manifest 結構範例

**IDE/CLI：**
```json
{
  "name": "Tool Name",
  "id": "tool-id",
  "vendor": "Vendor Name",
  "description": "Brief description",
  "websiteUrl": "https://...",
  "docsUrl": "https://...",
  "latestVersion": "1.0.0"
}
```

**模型：**
```json
{
  "name": "Model Name",
  "vendor": "Vendor",
  "id": "model-id",
  "size": "70B",
  "contextWindow": 128000,
  "maxOutput": 4096,
  "pricing": {...},
  "urls": {...}
}
```

## 後續步驟

- 瀏覽 [AI Coding Stack](/ai-coding-stack) 以探索工具
- 查看 `manifests/` 目錄，瞭解詮釋資料的組織方式
- 閱讀 [CLAUDE.md](https://github.com/aicodingstack/aicodingstack.io/blob/main/CLAUDE.md) 以取得詳細的貢獻指南
- 提交第一項貢獻，協助擴充目錄
