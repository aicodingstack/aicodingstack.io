# Bienvenue

Bienvenue dans la documentation de AI Coding Stack. AI Coding Stack est un répertoire complet et un référentiel de métadonnées pour l'écosystème de codage IA.

## Qu'est-ce que AI Coding Stack ?

AI Coding Stack a deux objectifs principaux :

1. **Un site web public** sur [aicodingstack.io](https://aicodingstack.io) pour découvrir et comparer les outils de codage IA
2. **Un référentiel de métadonnées maintenu par la communauté** contenant des informations sélectionnées sur les outils de codage, les modèles et les plateformes

## Fonctionnalités clés

### Couverture complète
Explorez un large éventail d'outils de codage IA dans plusieurs catégories :
- **IDEs** - Environnements de développement intégrés avec intégration IA
- **CLIs** - Assistants de codage IA en ligne de commande
- **Modèles** - Grands modèles de langage optimisés pour les tâches de codage
- **Fournisseurs** - Fournisseurs d'API LLM et plateformes

### Piloté par la communauté
Toutes les métadonnées sont maintenues dans des fichiers de manifeste JSON, ce qui facilite la contribution, la mise à jour et l'amélioration des informations sur divers outils par la communauté.

### Découverte facile
Parcourez, comparez et découvrez les bons outils de codage IA pour votre flux de travail via notre interface web intuitive.
