# Premiers Pas

AI Coding Stack est un répertoire complet et un référentiel de métadonnées pour l'écosystème de codage IA. Ce guide vous aidera à comprendre comment utiliser le site web et contribuer au projet.

## Explorer le Stack

### Parcourir les Catégories

Visitez [aicodingstack.io](https://aicodingstack.io) pour explorer différentes catégories d'outils de codage IA :

- **IDEs** - Trouvez des environnements de développement intégrés alimentés par l'IA (VS Code, Cursor, TRAE)
- **CLIs** - Explorez les assistants de codage IA en ligne de commande (Codex, Claude Code)
- **Modèles** - Comparez les grands modèles de langage pour le codage (Kimi K2, DeepSeek V3.1, GLM 4.5, Qwen3 Coder)
- **Fournisseurs** - Examinez les fournisseurs d'API LLM (DeepSeek, Moonshot, SiliconFlow, OpenRouter)

### Comparer les Outils

Utilisez le site web pour comparer différents outils côte à côte, en examinant leurs fonctionnalités, capacités et liens vers la documentation officielle.

## Contribuer aux Métadonnées

AI Coding Stack est maintenu par la communauté. Vous pouvez contribuer en ajoutant de nouveaux outils ou en mettant à jour les entrées existantes dans nos fichiers de manifeste.

### Comprendre les Manifestes

Toutes les métadonnées d'outils sont stockées dans des fichiers JSON dans le répertoire `manifests/` :

- `ides.json` - Métadonnées d'IDE
- `clis.json` - Métadonnées d'outils CLI
- `models.json` - Métadonnées de modèles LLM
- `providers.json` - Métadonnées de fournisseurs d'API

### Ajouter un Nouvel Outil

1. Clonez le dépôt
2. Localisez le fichier de manifeste approprié dans `manifests/`
3. Ajoutez votre entrée en suivant le schéma existant
4. Assurez-vous que toutes les URL sont accessibles
5. Soumettez une demande d'extraction

### Exemples de Schémas de Manifeste

**Pour les IDEs/CLIs :**
```json
{
  "name": "Nom de l'Outil",
  "id": "tool-id",
  "vendor": "Nom du Fournisseur",
  "description": "Description brève",
  "websiteUrl": "https://...",
  "docsUrl": "https://...",
  "latestVersion": "1.0.0"
}
```

**Pour les Modèles :**
```json
{
  "name": "Nom du Modèle",
  "vendor": "Fournisseur",
  "id": "model-id",
  "size": "70B",
  "contextWindow": 128000,
  "maxOutput": 4096,
  "pricing": {...},
  "urls": {...}
}
```
