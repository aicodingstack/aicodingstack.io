# ようこそ

AI Coding Stack のドキュメントへようこそ。AI Coding Stack は AI コーディングエコシステム向けの包括的なディレクトリおよびメタデータリポジトリです。

## AI Coding Stack とは？

AI Coding Stack には 2 つの主な目的があります：

1. **公開ウェブサイト** [aicodingstack.io](https://aicodingstack.io) - AI コーディングツールの発見と比較
2. **コミュニティが管理するメタデータリポジトリ** - コーディングツール、モデル、プラットフォームに関するキュレーションされた情報を収録

## 主な機能

### 包括的なカバレッジ
複数のカテゴリにわたる幅広い AI コーディングツールを探索：
- **IDE** - AI を統合した開発環境
- **CLIs** - コマンドライン AI コーディングアシスタント
- **Models** - コーディングタスクに最適化された大規模言語モデル
- **Providers** - LLM API プロバイダーおよびプラットフォーム

### コミュニティ主導
すべてのメタデータは JSON マニフェストファイルで管理されており、コミュニティが簡単に貢献、更新、および改善できます。

### 簡単な発見
直感的なウェブサイトインターフェースを使用して、ワークフローに適した AI コーディングツールを閲覧、比較、発見できます。
