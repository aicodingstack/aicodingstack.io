# Selamat Datang

Selamat datang di dokumentasi AI Coding Stack. AI Coding Stack adalah direktori komprehensif dan repositori metadata untuk ekosistem coding AI.

## Apa itu AI Coding Stack?

AI Coding Stack memiliki dua tujuan utama:

1. **Situs web publik** di [aicodingstack.io](https://aicodingstack.io) untuk menemukan dan membandingkan alat coding AI
2. **Repositori metadata yang dikelola komunitas** yang berisi informasi kurasi tentang alat coding, model, dan platform

## Fitur Utama

### Cakupan Komprehensif
Eksplorasi berbagai alat coding AI dalam beberapa kategori:
- **IDEs** - Lingkungan pengembangan terintegrasi dengan integrasi AI
- **CLIs** - Asisten coding AI baris perintah
- **Models** - Model bahasa besar yang dioptimalkan untuk tugas coding
- **Providers** - Penyedia API LLM dan platform

### Digerakkan Komunitas
Semua metadata dipelihara dalam file manifest JSON, sehingga memudahkan komunitas untuk berkontribusi, memperbarui, dan meningkatkan informasi tentang berbagai alat.

### Penemuan Mudah
Telusuri, bandingkan, dan temukan alat coding AI yang tepat untuk alur kerja Anda melalui antarmuka situs web yang intuitif.
